# 差分とロールバック

このガイドでは、DDLBuilder でテーブル構造の変更を比較し、ALTER スクリプトとロールバックスクリプトを作成する方法と、バージョン履歴を確認して再生する方法を説明します。

## 利用シーン

既存の業務テーブルのフィールド、型、インデックスを変更するときに、リリース前にリリース用スクリプトとロールバックスクリプトを用意する場面で使います。

---

## 操作手順

### 1. 構造の差分を確認する
1. 「ワークスペース」で保存済みテーブルを読み込みます。
2. エディターでフィールドの追加・削除、型の変更、インデックスの調整を行います。
3. テーブル構成エリアで **その他** をクリックし、**スキーマの変更を表示する** を選びます。
4. **テーブル構造の差分** ダイアログで、テーブル構成、フィールド（追加、削除、名前変更、属性の変更）、インデックスの変更を確認します。

### 2. ALTER スクリプトとロールバックスクリプトをコピーする
- **変更スクリプト** エリアで **コピー** をクリックすると、リリース用の ALTER 文を取得できます。
- **ロールバックスクリプト** エリアを展開し、**ロールバックをコピー** をクリックします。ロールバックスクリプトは逆向きの ALTER 文で、上の変更を取り消すために使います。

### 3. バージョン履歴とロールバック
- 保存済みテーブルを読み込んだ後、テーブル構成エリアで **バージョン履歴** をクリックします。
- テーブルを保存するたびに記録されたバージョン、保存日時、変更の概要を確認します。
- 過去のバージョンを 1 つ選び、**このバージョンにロールバックする** をクリックすると、エディターの内容がそのバージョンに戻ります。

### 4. スキーマの変更を再生する
- **バージョン履歴** ダイアログで **タイムラインを再生** をクリックします。
- プレーヤーはバージョン順に 1 フレームずつ、初期バージョンから最新バージョンまでのテーブル構造の変化を表示します。

---

## 完了のチェックリスト

- [ ] 差分に今回の変更がすべて含まれ、名前を変えたフィールドが名前変更として表示されている。
- [ ] ALTER スクリプトの構文が対象データベースのバージョンに合っている。
- [ ] 対応するロールバックスクリプトを保管し、リリース計画の障害時の手順にしている。
- [ ] バージョン履歴で過去のバージョンを見つけ、ロールバックできる。

## 注意事項

::: warning 本番データの互換性リスク
ALTER スクリプトとロールバックスクリプトが扱うのは構造定義だけです。フィールド長の短縮、型の強制変換、デフォルト値のない NOT NULL 列の追加を含む場合は、実行前に本番の既存データの移行と互換性を評価してください。
:::

- **スキーマの変更を表示する** は、保存済みテーブルを読み込んで実際に変更を加えた後にだけ表示されます。一度も保存していない下書きには基準となるバージョンがないため、この項目は表示されません。
- テーブルを上書き保存するたびに、バージョン履歴が 1 件追加されます。
