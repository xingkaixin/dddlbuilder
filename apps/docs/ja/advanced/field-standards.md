# フィールド標準ライブラリと業務辞書

フィールド標準は、業務概念とそのフィールド定義をそろえるために使います。例えば「注文金額」を `amount decimal(18,2)` と定義し、単位「元」と業務上の意味を記録したうえで、各テーブルが同じ標準に従っているかを確認します。

## 標準を作成する

1. テーブルを開き、フィールドツールバーで **フィールド標準ライブラリ** をクリックします。
2. **標準を作成** をクリックします。または「現在のテーブルのフィールド」を選んでから **このフィールドから標準を作成** をクリックします。
3. 業務名、業務定義、業務単位を入力します。
4. 標準フィールドの名前、型、説明、NULL 許容、デフォルト値、更新方式、列挙定義を編集します。
5. **標準を保存** をクリックします。1 つの標準は 1 つのフィールドを定義します。業務単位と業務定義は説明用の情報で、データを自動で変換したり DDL に書き込んだりはしません。

## 参照と更新

標準と現在のテーブルのフィールドを選ぶと、パネルに現在の値と標準の値が並んで表示され、差分が強調表示されます。

- **変更せずに関連付け**：参照を記録し、現在のフィールドの内容はそのまま残します。後で確認するときに使います。
- **標準を適用して関連付け**：パネルにある標準の属性で、選択したフィールドを上書きします。フィールドの識別情報は保持します。
- **標準フィールドを追加**：現在のテーブルに、その標準を参照するフィールドを追加します。同名のフィールドがすでにある場合は追加できません。
- **関連付けを解除**：フィールドの内容を残したまま、標準への参照を外します。

標準を編集しても、既存のフィールドは自動では更新されません。「このテーブルの標準参照」に差分の件数が表示されます。**差分を確認** をクリックし、内容を確かめてから適用するかを決めてください。フィールドを変更した後は、通常どおりテーブルを保存する必要があります。データベースの移行も別途実行してください。

## 保存済みテーブルを確認する

**保存済みテーブルを確認** をクリックすると、現在のワークスペースの保存済みテーブルにある参照と差分を確認できます。同名でも関連付けられていないフィールドも一覧に表示されます。未保存の下書きは確認の対象外です。結果は確認した時点のスナップショットなので、テーブルを変更した後は再確認してください。修正が必要な場合は、対象のテーブルを開き、標準ライブラリで内容を確かめてから適用します。

## 保存と共有

標準ライブラリは現在のブラウザーに保存され、アカウントのワークスペースとは独立しています。JSON にエクスポートしてバックアップや共有に使えます。インポート時は、標準の名前と、同じ ID で上書きされる件数をプレビューし、確定後にマージします。インポートできるファイルの上限は 2 MiB、標準 1000 件です。

フィールドの参照は、テーブルの保存、共有、アカウント同期とともに引き継がれます。他の端末や共同作業者が同じ標準 ID を解決するには、同じ標準ライブラリをインポートする必要があります。標準を削除しても、テーブルのフィールドは削除されません。参照先のない参照は残り、「標準が見つかりません」と表示されます。同じ ID の標準を再インポートすると元に戻ります。
