# SQL のレビューと説明

このページでは、**AIレビュー** で現在のテーブルの DDL を確認する方法と、**選択範囲を説明** で AI に SQL の一部を説明させる方法を紹介します。

## 利用場面

テーブル構造を DBA の審査に出す前やリリース前に、自分で一度確認します。見慣れない SQL を読むときに、各句の役割を 1 つずつ確認します。

---

## 操作手順

### 1. AIレビュー
1. 現在のテーブルにフィールドが設定され、DDL が生成されていることを確認します。
2. 生成結果の「DDL」タブで **AIレビュー** をクリックします。
3. スコアと提案を確認します。
   - AI は、命名規則、データ型の選択、インデックス設計、整合性制約、拡張性、パフォーマンスの 6 つの観点からレビューし、1〜10 のスコアと短いまとめを返します。
   - 提案は 1 件ずつ表示されます。パフォーマンスの問題には「重大」または「警告」が付きます。
4. フィールドの追加・変更・削除と、インデックスの追加・削除の提案には **適用** ボタンがあります。クリックすると、変更がフィールドまたはインデックスの設定に書き込まれます。パフォーマンスの指摘と一般的な提案は参考情報で、自動では適用できません。
5. **AIレビュー** の横にある履歴アイコンをクリックすると「レビュー履歴」が開き、過去のレビューのスコアと提案を確認できます。

### 2. 選択した SQL の説明
1. 生成結果の SQL コードエリアで、文または句をマウスで選択します。たとえばインデックスのオプション、パーティション定義、ストレージパラメーターです。
2. 選択範囲の横に **選択範囲を説明** ボタンが表示されます。サインインしていない場合、ボタンには「説明するにはサインインしてください」と表示されます。
3. **選択範囲を説明** をクリックすると、AI がその SQL の役割と要点を説明します。

---

## 完了の確認

- [ ] 現在のテーブルで AIレビューを実行し、「重大」が付いた問題をすべて対処または確認した。
- [ ] 適用した提案がテーブル設定に反映され、DDL が更新されている。
- [ ] レビューで説明が必要な複雑な SQL の部分に、すべて説明がある。

## 注意事項

::: tip 提案を適用する前に業務ルールを確認する
AIレビューの提案は、一般的なデータベース設計の助言です。特別な業務ルールに関わる変更（意図的に残した非正規化の冗長フィールドなど）は、実際の要件に合わせて採用するかどうかを決めてください。
:::

- DDL が生成されていない場合、**AIレビュー** ボタンは使えません。データベースの種類が SQLite / D1 の場合も使えません。
- **選択範囲を説明** を使うときは、文または句を最後まで選択してください。
