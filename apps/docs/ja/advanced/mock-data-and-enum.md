# Mock データと論理列挙

このガイドでは、DDLBuilder で Mock のテストデータを生成する方法と、フィールドに論理列挙を設定する方法を説明します。

## 利用シーン

開発や結合テストの段階でテストデータを用意する場面、SQL クエリを検証する場面、ステータスコードや種別コードなどのフィールドに値と意味を記録する場面で使います。

---

## 操作手順

### 1. Mock データを生成してエクスポートする
1. テーブル構造のフィールドとデータ型の設定が済んでいることを確認します。
2. フィールドツールバーで **モックデータ** をクリックし、**モックデータジェネレーター** を開きます。
3. 生成の条件を設定します。
   - 生成する行数を指定します（1〜100 行）。
   - 生成結果をプレビューします。ジェネレーターはフィールドの型に応じて値を生成します。フィールド名やコメントに email、phone、address などのキーワードが含まれる場合は、それに合った形式の値を生成します。
4. データをエクスポートします。
   - **INSERT SQL**、**CSV**、**JSON** のタブで形式を切り替えます。
   - **コピー** または **ダウンロード** をクリックし、ローカルのテスト用データベースや API のデバッグツールに取り込みます。

### 2. フィールドの論理列挙を設定する
ステータスコード、審査状態、ユーザー種別など、取り得る値が決まっているフィールドが対象です。
1. フィールドの表で対象のフィールドを探し、フィールドの型のセルにある編集アイコンをクリックして **列挙値の編集** ダイアログを開きます。
2. 列挙値（例: `10`、`PAID`）を入力し、Enter キーを押すか **追加** をクリックします。**中国語** と **英語** の欄に意味（例: `已支付`、`Paid`）を入力します。
3. 列挙項目の色ブロックをクリックして色を選びます。例えば、緑は成功、赤は却下、黄は保留中を表します。フィールドの型のセルには、列挙値がこの色で表示されます。
4. 列挙項目の左側にあるハンドルをドラッグして順序を変えます。
5. **OK** をクリックします。列挙の設定は、下書きと保存済みテーブルとともに保存されます。

---

## 完了のチェックリスト

- [ ] エクスポートした Mock データをテスト用データベースに取り込める。
- [ ] 論理列挙がフィールドの業務上の値をすべて含み、各値にコメントと色がある。
- [ ] 保存済みテーブルを読み込み直しても、列挙の設定が残っている。

## 注意事項

::: tip 本番の機密データの扱い
モックデータジェネレーターはランダムな値だけを生成し、実際の業務データは含みません。マスキングしていない実ユーザーのデータを、テスト環境でそのまま使わないでください。
:::

- Mock データは 1 つのテーブルのフィールドごとに独立して生成され、テーブルをまたぐ外部キーは確認しません。テスト用データベースに挿入するときは、参照先テーブルのデータを先に挿入してください。
- 論理列挙はフィールドの型を変えず、データベースの制約も生成しません。DDL を生成すると、列挙値とそのコメントがフィールドのコメントに追記されます。データベースの `ENUM` 型が必要な場合は、フィールドの型で対象方言の `ENUM` を選んでください。
