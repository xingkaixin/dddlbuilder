# PostgreSQL CREATE TABLE & インデックス生成ツール

DDLBuilder は PostgreSQL 本来の構文に沿ったオンライン DDL 生成ツールです。`GENERATED BY DEFAULT AS IDENTITY`、Schema 修飾テーブル名、独立した `COMMENT ON` 文、`ALTER TABLE ... ADD CONSTRAINT` 主キー、`ASC`/`DESC` 指定の `CREATE [UNIQUE] INDEX`、`WITH (fillfactor = ...)` をそのまま出力します。

## 実際の DDL 出力例：インデックスと fillfactor を備えた決済注文テーブル

本ページのボタンをクリックすると、以下の PostgreSQL `app.payment_orders` テーブルを新しい下書きとしてすぐに開けます：

```sql
CREATE TABLE app.payment_orders (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY NOT NULL,
  order_no VARCHAR(64) NOT NULL,
  user_id BIGINT NOT NULL,
  amount_cents BIGINT NOT NULL DEFAULT 0,
  currency CHAR(3) NOT NULL DEFAULT 'CNY',
  metadata JSONB,
  paid_at TIMESTAMP WITH TIME ZONE,
  created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP
) WITH (fillfactor = 90);
COMMENT ON TABLE app.payment_orders IS '支付订单表';
COMMENT ON COLUMN app.payment_orders.id IS '主键ID';
COMMENT ON COLUMN app.payment_orders.order_no IS '外部订单号';
COMMENT ON COLUMN app.payment_orders.user_id IS '用户ID';
COMMENT ON COLUMN app.payment_orders.amount_cents IS '金额（分）';
COMMENT ON COLUMN app.payment_orders.currency IS '币种';
COMMENT ON COLUMN app.payment_orders.metadata IS '扩展元数据';
COMMENT ON COLUMN app.payment_orders.paid_at IS '支付时间';
COMMENT ON COLUMN app.payment_orders.created_at IS '创建时间';

ALTER TABLE app.payment_orders ADD CONSTRAINT pk_payment_orders PRIMARY KEY (id);
CREATE UNIQUE INDEX uk_payment_orders_order_no ON app.payment_orders (order_no ASC);
CREATE INDEX idx_payment_orders_user_created ON app.payment_orders (user_id ASC, created_at DESC);
```

## 主な機能

- **PostgreSQL 固有の正確な構文**：独立した `COMMENT ON`、名前付き `PRIMARY KEY`、`CREATE [UNIQUE] INDEX` を正確に生成します。
- **Schema 名前空間**：Schema 名を設定すると、テーブル定義、コメント、インデックス、Prisma の `@@schema(...)` まで一貫して反映されます。
- **ストレージオプション**：**詳細設定 → テーブルオプション** から `tablespace` や `fillfactor` を設定できます。
- **Citus 分散テーブル**：**PostgreSQL (Citus)** を選べば `SELECT create_distributed_table(...)` を自動追記します。
- **構造差分と互換性評価**：2 つの PostgreSQL スキーマの差分比較や、MySQL からの移行互換性評価に対応しています。

## 手順

1. 本ページのボタンから `app.payment_orders` プリセットを開きます。
2. Schema 名、カラム型（`JSONB`、`UUID`、`TIMESTAMPTZ` など）、デフォルト値を編集します。
3. **インデックス設定** でユニークインデックスと複合インデックスのソート順を調整します。
4. **詳細設定 → テーブルオプション** で `fillfactor` や表領域を設定します。
5. 生成された DDL をコピーするか、**ORM モデル** タブで Prisma / TypeORM / SQLAlchemy / GORM / JPA コードを出力します。

## よくある質問

### PostgreSQL のテーブルコメントとカラムコメントはどのように出力されますか？

PostgreSQL は `CREATE TABLE` 内のインラインコメントに非対応のため、DDLBuilder はテーブル定義の後ろに標準の `COMMENT ON TABLE` と `COMMENT ON COLUMN` 文を自動出力します。

### IDENTITY 主キーや JSONB・TIMESTAMPTZ に対応していますか？

対応しています。自動採番を有効にすると `GENERATED BY DEFAULT AS IDENTITY` が出力され、`JSONB`、`TIMESTAMPTZ`、`CHAR`、`VARCHAR` など PostgreSQL の型を利用できます。

### PostgreSQL Citus の分散テーブルにも対応していますか？

対応しています。データベースを **PostgreSQL (Citus)** に切り替えると、リファレンステーブルまたは分散キーを設定して `create_distributed_table` 文を出力できます。
