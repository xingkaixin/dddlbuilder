# 変更履歴

## [0.22.0] - 2026-08-27
### 追加
- **WebMCP ブラウザ側 Agent ツール対応**: Model Context Protocol (MCP) に準拠したツールセットをブラウザ上で提供し、外部の AI Agent がワークスペースを読み取ってテーブル構造、フィールド、インデックス、リレーションの変更を提案できるようになりました。提案されたすべての変更は、適用前に変更レビューダイアログで手動確認できます。
- **Schema Diff 手動移行ガイダンス**: スキーマ差分比較やバージョン履歴比較において、自動 `ALTER` DDL では安全に適用できない破壊的な変更（列の削除/名前変更、非互換な型変換など）を自動検出し、手動移行のガイダンスと手順を提示します。

### 改善
- **安定したエンティティ識別と同期収束**: 下書き、保存済みテーブル、フィールド、バージョン履歴、レビュー記録を安定したエンティティ ID に紐付け、名前変更、ドラッグ＆ドロップ移動、移行時にも関連付けを維持します。Yjs リアルタイム同期は永続化完了を確認した後に同期完了と判定し、高速なタブ切り替えや再接続による状態の巻き戻りを防ぎます。
- **フォルダーの再帰的削除とゴミ箱の信頼性向上**: フォルダーの削除時に含まれるすべての下書き・テーブルを再帰的にゴミ箱へ移動し、関連履歴を整理します。操作結果の永続化ステータスと再試行処理を強化しました。
- **SQL 方言解析と DDL 出力の精度向上**: リテラル既定値と SQL 関数/式による既定値を明確に区別し、Prisma、TypeORM、SQLAlchemy、GORM、JPA などの ORM 出力に正確に反映します。PostgreSQL の識別子の大文字・小文字の保持と `IDENTITY` 列の状態遷移サポートを改善しました。
- **ALTER DDL の依存順序制御とロールバック生成**: 外部キーやインデックスの依存関係に基づいて変更ステートメントをトポロジカルにソートし、依存関係を先に解除してから変更を実行します。正方向の差分から正確な逆方向ロールバック DDL を生成します。

### 修正
- **AI Patch の依存検証とストリーム中断の復帰**: AI によるインデックス提案やスキーマパッチの適用前に関連フィールドの整合性を検証し、無効な参照を除去します。ストリーミング生成の中断時にも一時状態を安全にリセットします。
- **AI クレジットと日次予算の安全な精算**: 安全な整数制約と日次リトライ予算の分離を適用し、通信切断時などの重複請求や残高の不整合を防止します。
- **ストレージ履歴の隔離と接続クリーンアップ**: テーブル削除時に関連するバージョン履歴とレビュー記録を確実に削除し、IndexedDB トランザクションのライフサイクルを改善して接続リークを防止します。

## [0.21.0] - 2026-08-25
### 追加
- **日本語の製品とドキュメントをサポート**: アプリ画面、AI 生成コンテンツ、ヘルプリンク、ドキュメントサイトを日本語で利用できるようになり、言語切り替えと日本語の検索メタデータにも対応しました。

### 改善
- **ワークスペースの起動と移行を保護**: サインイン後はローカル Y.Doc の読み込みが完了してから編集を開始するため、起動中の変更が上書きされなくなりました。旧形式のローカルデータはデバイスごとに一度だけ移行され、中断後も安全に再開できます。
- **ワークスペース操作の一貫性を向上**: 一括インポート、AI による Schema 変更、フィールド削除、エンティティ更新をアトミックに反映します。安定したエンティティ ID と厳密なワークスペース範囲管理により、再読み込みや同期の後もタブ、フォルダー、ゴミ箱、最新の編集状態が一致します。

### 修正
- **SQL、DDL、ORM 出力の正確性**: 複数テーブルの SQL 解析でフィールドを所属テーブルに正しく保持し、Schema 差分で名前変更とプロパティ変更の意図を維持します。Prisma、TypeORM、SQLAlchemy、GORM、JPA では有効なリレーションを生成します。
- **AI Schema 編集のフィードバック**: レビューパネルに Schema 差分全体を表示し、生成された変更を適用前に検証します。変更に失敗した場合に現在のテーブルが部分的に更新されることも防ぎます。
- **AI クレジットと予算の精算**: リクエストが中断してもクレジットが予約されたまま残らなくなりました。精算、返金、日次予算の予約は明確な完了状態に収束し、重複請求や重複返金を防ぎます。

## [0.20.0] - 2026-07-26
### 追加
- **ER 関係作成ウィザード**: ER 図のソース フィールドからターゲット フィールドにドラッグし、多対 1 または 1 対 1 のカーディナリティ、必須またはオプションの参加、更新/削除アクション、およびインデックス戦略を確認します。システムは外部キーを作成し、フィールドの NULL 可能性を更新し、必要なインデックスをまとめて追加します。
- **リレーションシップの安全性の検証**: ウィザードは、ターゲット テーブルの単一列の主キーまたは一意キーのみを参照し、重複するリレーションシップ、重複する制約名、および無効な `SET NULL` 構成をブロックします。型の不一致は作成前に報告されます。
- **認証のための人による検証**: デプロイメントで Cloudflare Turnstile を構成すると、サインインとサインアップで人間による検証トークンが検証され、自動登録とアカウント API の悪用が削減されます。

### 改善されました
- **全幅折りたたみレイアウト**: ワークスペースのサイドバーまたは DDL 出力パネルを折りたたんでも、空のレールが残らないようになりました。展開コントロールはコンテンツ領域に移動するため、テーブル編集で水平方向のスペース全体を使用できます。
- **一貫したフォームとオーバーレイのインタラクション**: ボタン、選択、チェックボックス、タブ、ダイアログ、メニューは、オーバーレイ間の信頼性の高いフォーカスとポインタの遷移を含む、一貫したインタラクション基盤を共有するようになりました。ドラッグ ハンドルとアプリケーション アイコンも 1 つのビジュアル システムを使用します。
- **大規模なテーブルとワークスペースのパフォーマンス**: フィールド編集により、無関係な行のレンダリングが回避され、インデックス フィルタリングとフォルダーのクリーンアップにより実行されるスキャンと書き込みの繰り返しが少なくなります。多くのフィールド、インデックス、またはフォルダーを使用しても、編集はより安定します。
- **ワークスペースの同期コンバージェンス**: エンティティの変更はアトミックにコミットされ、インポートは安全に再試行でき、古いハイドレーション作業はキャンセルされるため、マルチデバイスおよび脆弱なネットワークのセッションが一貫した状態に回復するのに役立ちます。

### 修正済み
- **空の状態とゴミ箱の回復**: 消去されたフィールド、インデックス、フォルダーが古い状態から再表示され、同期回復中にローカルのゴミ箱エントリが失われる問題を修正します。
- **スキーマ diff と変更 DDL**: フィールド名の変更はプロパティの変更とともに適用され、重複または類似のフィールドは決定論的に一致し、方言固有の制約名とロールバック ステートメントがより正確に生成されます。
- **フィールド編集フォーカス**: フォーカスされたフィールド入力の周囲の二重境界線を修正し、選択と編集で 1 つの明確なフォーカス処理を使用できるようにします。
- **アトミック AI クレジット決済**: AI クレジットの予約、決済、返金操作はアトミックであり、同時リクエストによる重複請求や残高の不一致を削減します。

### 導入とセキュリティ
- **D1 移行プリフライト**: ローカル ワーカーの起動により、保留中の移行が自動的に適用されます。 Cloudflareのデプロイメントでは、D1リカバリポイントを記録し、リモート移行を実行し、起動後のテーブル欠落障害を防ぐために公開前に必要なテーブルを検証します。
- **リクエストとセッションの保護**: アカウント、管理者、共有、および AI エンドポイントにより、リクエストのサイズ、レート、セッションの検証が強化されます。 AI 応答本文はログに書き込まれなくなり、機密コンテンツの露出が減少します。

## [0.19.0] - 2026-05-06
### 追加
- **ワークスペース Yjs チェックポイント**: リアルタイム同期により、Yjs 更新がサーバー側チェックポイントに圧縮されるようになりました。これにより、コールド スタートまたは再接続後に Durable Object が完全なワークスペース スナップショットから回復できるようになり、長時間の編集セッション後の回復コストが削減されます。
- **同期ステータス インジケーター**: ヘッダーには、ローカル保存、同期中、クラウド同期、オフライン ローカル保存、および同期失敗の状態が表示され、同期失敗時の再試行アクションが表示されます。
- **同期コストと健全性の観察可能性**: ワーカーの構造化ログには、リリース後に同期コストと健全性を追跡するための D1 読み取りと書き込み、チェックポイント、永続オブジェクト接続、更新、圧縮メトリクスが含まれるようになりました。

### 改善されました
- **ワークスペースのリアルタイム同期の信頼性**: WebSocket の更新では、バッチ処理、接続タイムアウトの検出、オンライン回復の更新、ページを離れる前のフラッシュがサポートされるようになり、弱いネットワークやマルチデバイスの編集を最新の状態に収束できるようになりました。
- **構造化されたマージ セマンティクス**: ワークスペース Y.Doc は、テーブル、フィールド、インデックス、フォルダーを詳細な構造として書き込むようになりました。リモート スナップショットを適用すると、ローカルの編集内容が保存され、フィールド レベルの変更がテーブル全体のスナップショットによって上書きされるリスクが軽減されます。
- **重複保存制御**: テーブル状態の比較では、デフォルト設定と意味のない違いが無視され、状態が変化していない場合にローカルおよびクラウドで保存が繰り返されることが削減されます。
- **ドキュメント検索の可視性**: ドキュメント ページには正規リンクと代替 hreflang リンクが含まれるようになり、`llms.txt` は拡張子なしのドキュメント パスを使用するため、検索エンジンと AI ツールは中国語と英語のドキュメントをより確実に識別できます。

### 修正済み
- **ローカル編集保護**: リモート Y.Doc スナップショットを適用すると、まだフラッシュされていないローカル編集が上書きされる可能性がある問題を修正します。オフライン回復と再接続により、保留中の同期コンテンツが積極的に更新されるようになりました。
- **開発 WebSocket 同期**: Vite dev サーバー プロキシが WebSocket をサポートするようになったため、ワークスペースのリアルタイム同期を開発環境および E2E 環境で直接検証できるようになりました。

## [0.18.0] - 2026-05-05
### 追加
- **AI による現在のテーブルの変更**: 自然言語による現在のテーブル構造の調整をサポートします。 AI は、テーブル名、フィールド、インデックス、データベース タイプに基づいて、レビュー可能なテーブル レベル、フィールド、インデックスの変更を生成します。選択した変更をワークスペースに適用する前に、各変更を承認または拒否できます。
- **AI インデックス最適化アドバイザー**: 一般的なクエリ SQL または低速クエリ スニペットの貼り付けをサポートします。 AI は、現在のフィールドと既存のインデックスに基づいて、インデックスの欠落、冗長インデックス、フィールド順序の最適化、クエリのリライトを推奨します。推奨されるインデックスはインデックス構成に直接追加できます。
- **リアルタイム ワークスペース同期**: サインイン後、下書き、保存されたテーブル、フォルダー、ゴミ箱はリアルタイム同期チャネルを通じて一貫性を維持するため、別のデバイスで更新、再度開く、またはサインインした後、最新のワークスペースを簡単に復元できます。
- **ワークスペースの増分同期と競合通知**: [設定] ページに [今すぐ同期] と競合通知が追加され、クラウドの変更をプルしたり、ローカルで保留中の変更をプッシュしたり、バージョンの競合を検査したりできるようになります。
- **フィードバック エントリ**: 使用中に問題や提案を送信するためのフィードバック エントリをヘッダー ツールバーに追加します。
- **多言語サイトマップ**: 検索エンジンが中国語と英語のドキュメントのバージョンを識別できるように、hreflang メタデータを含むドキュメント サイトマップを追加します。

### 改善されました
- **AI スキーマ編集エクスペリエンス**: AI 生成は最初に変更リストに変換され、確認後にのみテーブル構成に書き込まれるため、既存の構造に対する小さなステップの編集がより安全になります。
- **ワークスペースの空の状態**: タブが開いていない場合、サンプル テーブルを直接作成、インポート、またはロードするための最近のアイテムとクイック アクションが表示されます。
- **設定レイアウト**: アカウント、クレジット、ワークスペースの同期コンテンツは、コンテンツの多いシナリオ、狭い画面、フルハイトのダイアログでも確実にスクロールするようになりました。
- **テーブル編集のコミット動作**: フィールド テーブルのセルは、選択が変更されると現在の編集をコミットし、編集後の余分な確認手順を減らします。
- **ワークスペースの読み込みフィードバック**: 同期または切り替え中の視覚的なジャンプを減らすために、タブの読み込み中にスケルトンを表示します。

### 修正済み
- **ワークスペース状態の同期の安定性**: タブの署名が変更された後に発生する可能性のある古い同期を修正し、フローの保存および切り替え中の誤った状態の書き込みを減らします。
- **ワークスペース スナップショットの書き込み**: 状態が変化していない場合のスナップショットの繰り返し更新を回避し、不必要なローカルとクラウドの同期圧力を軽減します。
- **永続性クリーンアップ フロー**: サインアウトおよびスコープ変更中に永続性リソースが解放されるのを待機し、残った接続によって引き起こされるエラーを削減します。

## [0.17.0] - 2026-04-29
### 追加
- **マルチタブ ワークスペース**: 同じワークスペース内で複数のタブを開くことをサポートし、それぞれが独立したテーブルとドラフト状態を管理します。タブは作成、閉じる、切り替え、ダーティステートのインジケーターをサポートしており、未保存の変更を閉じる前に保存の確認が行われます。
- **外部キー管理と ER 図**: カスケード ルールや制約の名前付けなど、テーブル関係を視覚的に設定するための外部キー構成パネルを追加します。 ER 図ビューアは、ドラッグ可能なノード、キャンバス ズーム、関係線のレンダリングを備えた React Flow ベースの実装にアップグレードされています。
- **ORM モデル生成**: DDL に加えて、Prisma、TypeORM、SQLAlchemy、GORM、および JPA の ORM モデル生成が追加され、ビジネス プロジェクトへの直接貼り付けが容易になります。
- **バッチ データ インポート**: フィールド名と型の自動認識を使用して、CSV、Excel、および JSON スキーマ ファイルからのテーブル構造のインポートをサポートします。 SQL バッチ インポートでは、競合検出とフィールド マージ戦略が追加され、手動入力が削減されます。
- **ビュー DDL 生成**: SELECT クエリ定義、フィールド エイリアス、および権限をサポートするビュー構成パネルを追加し、ターゲット データベースに対応する CREATE VIEW ステートメントを自動的に生成します。
- **ルーチン テンプレート DDL 生成**: ストアド プロシージャ、関数、トリガー用のルーチン テンプレート DDL 生成を追加します。
- **スキーマ タイムライン再生**: 視覚的なタイムライン プレーヤーをバージョン履歴に追加し、古い状態から新しい状態へのスキーマの進化を段階的に再生できるようにします。
- **Schema lint パネル**: 命名規則と型ルールに基づいて、テーブル構造、フィールド、インデックス設計の潜在的な問題を自動的に検出する組み込みの Schema lint パネルを追加します。
- **AI コメント生成**: AI テーブルの生成とレビューにより、テーブルとフィールドに対する中国語のビジネス コメントが自動的に生成され、文書化の手間が軽減されます。
- **モック データ ジェネレーター**: フィールド タイプと制約に基づいてテスト データを自動的に生成するモック データ ジェネレーターを追加し、開発とテスト用のバッチ エクスポートをサポートします。
- **論理列挙型エディタ**: フィールドは、列挙型項目の追加、削除、並べ替え、色分けを行うためのインライン エディタで論理列挙型値をサポートします。 Enum メタデータは、ドラフトおよび保存されたテーブルとともに保持されます。
- **テーブル ブループリント テンプレート**: ワンクリックで完全なテーブル構造を生成し、現在のワークスペースに直接適用できる一般的なビジネス シナリオ テーブル ブループリント (ユーザー、注文、ログ CRUD テーブルなど) を追加します。
- **保存されたテーブルのゴミ箱**: 保存されたテーブルは、ゴミ箱を使用した論理的な削除、単一項目の復元、およびバッチを空にすることをサポートしています。ドラフトは、誤って削除されるリスクを軽減するために、ダーティ状態インジケーターとゴミ箱管理もサポートしています。
- **ワークスペース サイドバーと複数のドラフト**: 複数の名前付きドラフトを作成および管理するためのワークスペース サイドバーを左側に追加します。ドラフトと保存されたテーブルはドロワー内に一緒に表示され、より明確に整理して検索できるようになります。
- **フィールド タイプ変更リスク検出**: 既存のフィールド タイプを変更する場合、システムは、運用上のインシデントを防ぐために、データ互換性リスク (文字列の切り捨て、精度の損失、暗黙的な変換失敗など) について警告します。
- **インデックス対応のストレージ見積もり**: ストレージ容量の見積もりにインデックス ボリュームが計算に含まれるようになり、合計容量の見積もりが実際の物理ディスク使用量に近づきます。
- **テーブル レベルのストレージ オプション**: データベース タイプごとに物理ストレージの動作を調整するために、fillfactor および Oracle 固有のストレージ パラメーター構成を追加します。
- **折りたたみ可能な出力パネルとコンパクトなレイアウト**: DDL 出力パネルは、編集スペースを解放するための折りたたみをサポートしています。フィールド構成テーブルには、小さな画面での情報密度を高めるためのコンパクト レイアウト モードが追加されています。
