# インデックス、権限、その他

このページでは、インデックス、権限付与の文（DCL）、「その他」タブのストレージパラメーター、ルーチンのコードの雛形の設定方法を説明します。

## 利用場面

フィールドを定義した後に、インデックス、権限付与、ストレージパラメーターを追加します。

---

## 設定ガイド

### 1. インデックスの設定（Index & Key）
「インデックス」タブで次の操作を行います。
- 「主キーの追加」：主キーにするフィールドを選びます。1 つのテーブルに主キーは 1 つだけです。
- 「一意のインデックスを追加する」：電話番号、メールアドレス、テナントコードなど、一意である必要があるフィールドに使います。
- 「インデックスの追加」：通常のインデックスを作成します。「フィールドの候補」から 1 つ以上のフィールドを選びます。複数のフィールドを選ぶと複合インデックスになります。
- 「インデックス名」：空欄の場合は自動で生成されます。形式は `idx_テーブル名_フィールド名` で、一意インデックスの接頭辞は `uk_` です。データベースの識別子の長さの上限を超える場合は切り詰められます。追加済みのインデックス名をダブルクリックすると変更できます。

### 2. AIインデックスアドバイザー
よく使うクエリにどのインデックスを作ればよいかわからない場合は、次のように操作します。
1. 「フィールド」のツールバーで「AI ツール」メニューを開き、「AIインデックスアドバイザー」をクリックします。
2. 「一般的なクエリ SQL」に、よく使うクエリやスロークエリの断片を 1 行に 1 つずつ貼り付け、「インデックスの分析」をクリックします。
3. AI は現在のフィールドと既存のインデックスに基づいて提案を出します。提案は「インデックス不足」「冗長インデックス」「順序の最適化」「クエリリライト」などのカテゴリに分かれます。
4. 提案を採用する場合は「インデックスの追加」をクリックします。インデックスが「インデックス」タブに追加され、DDL も更新されます。

### 3. 権限の設定（DCL）
「権限」タブで次の操作を行います。
- 被付与者（ユーザーまたはロール。例：`app_user`、`readonly_role`）を入力し、「追加」をクリックします。
- 「生成結果」の「DCL」タブには、被付与者ごとに `GRANT SELECT ON テーブル名 TO 被付与者;` が 1 文ずつ生成されます。
- 「スキーマ名」を入力した場合、文中のテーブル名にスキーマの接頭辞が付きます。

### 4. その他の設定（ストレージパラメーターとデータベース固有のオプション）
「その他」タブで「その他のオプションを有効にする」スイッチをオンにすると、現在のデータベースがサポートするストレージパラメーターを設定できます。
- **エンジンと文字コード**：MySQL / MariaDB の `ENGINE`（InnoDB など）、`CHARACTER SET`（`utf8mb4` など）、`COLLATE`。
- **物理ストレージのパラメーター**：テーブルスペース（`TABLESPACE`）、PostgreSQL の `fillfactor`、Oracle の `PCTFREE`、`INITRANS` などの固有パラメーター。

### 5. ルーチンのコードの雛形
「生成結果」で「ルーチン」タブに切り替え、テンプレート（ストアドプロシージャ、関数、自動更新タイムスタンプトリガー、監査ログトリガー、カスタムトリガー）を選びます。名前などのパラメーターを入力すると雛形のコードが生成されます。業務ロジックはデータベース側で追加します。

---

## 確認と完了の目安

- [ ] よく使うクエリと絞り込みに使うフィールドにインデックスがあり、一意である必要があるフィールドに一意インデックスがある。
- [ ] インデックス名が重複しておらず、フィールドが選ばれていないインデックスがない。
- [ ] 権限付与が必要なユーザーとロールがすべて追加され、「DCL」タブに被付与者ごとの `GRANT` 文がある。
- [ ] その他のオプションを有効にした場合、ストレージパラメーターが `CREATE TABLE` 文の末尾に出力されている。

## 注意事項

::: tip その他の設定が反映されない場合
「その他」で設定したパラメーターが DDL に出力されない場合は、パネル上部の「その他のオプションを有効にする」スイッチがオンになっているか確認してください。
:::

- **主キーは 1 つだけ**：1 つのテーブルに主キーは 1 つだけです。主キーがある状態で「主キーの追加」をクリックすると、「主キーはすでに存在します」と表示されます。
- **被付与者が空の場合**：被付与者を追加していない場合、「DCL」タブには `-- 被付与者を構成してください` と表示されます。CREATE TABLE の DDL には影響しません。
