# DDL 出力と共有

このページでは、CREATE TABLE の DDL、権限付与の DCL、ORM モデル、ルーチンのコードを確認・コピーする方法と、読み取り専用のリンクでテーブル構造を共有する方法を説明します。

## 利用場面

テーブル構造の設計が終わった後に、SQL をデータベースのレビューやリリースのチケットに渡す、ORM のコードを業務プロジェクトに入れる、同僚にリンクを送って見てもらう、といった場面で使います。

---

## 操作ガイド

### 1. 各出力を確認する
「生成結果」には次のタブがあります。
- 「DDL」：主キー、フィールド制約、コメント、インデックス、パーティションを含む `CREATE TABLE` 文です。「スキーマ名」を入力した場合、テーブル名は `schema.table` の形式で出力されます。
- 「DCL」：被付与者ごとの `GRANT SELECT` 文です。
- 「ORM」：「ORM フレームワーク」で Prisma、TypeORM、SQLAlchemy、GORM、JPA のいずれかを選ぶと、対応するモデルコードが生成されます。
- 「ルーチン」：ストアドプロシージャ、関数、トリガーのコードの雛形です。オブジェクトの種類がビューの場合、`CREATE VIEW` 文は「DDL」タブに表示されます。

### 2. コードのコピーと整形
- 各タブの「DDLのコピー」「DCL のコピー」「ORMコードをコピーする」「ルーチンをコピー」をクリックすると、コードがクリップボードにコピーされます。
- 「DDL」タブでは「コンパクト」と「整列」の 2 つの形式を切り替えられます。コピーされる内容は、表示中の形式と同じです。

### 3. 設計エリアと生成結果を切り替える
タブバー右側の「分割プレビュー」をオンにすると、設計エリアが上、生成結果が下に表示されます。フィールドが多い場合は、生成結果の上部にある「出力パネルを折りたたむ」をクリックすると、設計エリアだけが表示されます。コードを見たいときは「生成結果」をクリックします。

### 4. 読み取り専用の共有リンクを生成する
1. 上部の「共有」をクリックします。
2. DDLBuilder が読み取り専用のリンクを生成し、クリップボードにコピーします。リンクの有効期限は 7 日間です。
3. リンクには、現在のテーブルのテーブル名、スキーマ名、フィールド、制約、インデックス、その他の設定が含まれます。

### 5. 受け取った人がコピーを保存する
- 共有リンクから開いたページは読み取り専用で、直接変更できません。
- 変更が必要な場合は、上部のバナーにある「コピーとして保存して編集」をクリックします。DDLBuilder はコピーを受け取った人のワークスペースに保存して開きます。以降に編集するのはこのコピーです。

## データベースのバージョンと特殊なオブジェクト

::: info データベースごとの詳細
- **Oracle のシノニム**：CREATE TABLE の DDL には `PUBLIC SYNONYM` が自動で追加されなくなりました。シノニムが必要な場合は、権限を持つ DBA が個別に作成してください。
- **MySQL の複雑なデフォルト値**：TEXT、BLOB、JSON などの型で定数のデフォルト値を使う場合、式の構文（`DEFAULT ('{}')` など）で出力されます。MySQL 8.0.13 以降が必要です。
- **エスケープの動作**：MySQL 系の文字列は、バックスラッシュエスケープが有効なモードを前提に出力されます。対象のセッションで `NO_BACKSLASH_ESCAPES` が有効な場合は、実行前にエスケープの扱いを確認してください。
:::

## 確認と完了の目安

- [ ] コピーした SQL や ORM のコードを対象のクライアントに貼り付けて、正常に実行またはコンパイルできる。
- [ ] 「スキーマ名」を入力した場合、すべての出力のテーブル名にスキーマの接頭辞が付いている。
- [ ] 共有リンクをシークレットウィンドウや他の人のパソコンで開くことができ、読み取り専用で表示される。
- [ ] 「コピーとして保存して編集」をクリックした後、コピーがワークスペースで開き、編集できる。
