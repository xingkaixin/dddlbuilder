# コアコンセプト

このページでは、DDLBuilder のワークスペース、下書きボックス、保存済みテーブル、読み取り専用の共有、出力の種類、アカウントの同期、AI クレジットについて説明します。

## 概念の関係図

```mermaid
graph TD
    Workspace[ワークスペース Workspace] --> Tabs[複数タブ Tabs]
    Workspace --> Drafts[下書き Drafts]
    Workspace --> SavedTables[保存済みテーブル Saved Tables]
    SavedTables --> Folders[フォルダー Folders]
    SavedTables --> Trash[ゴミ箱 Trash]
    
    Tabs --> Output[出力]
    Output --> DDL[DDL テーブル / インデックス / パーティション]
    Output --> DCL[DCL 権限管理]
    Output --> ORM[ORM モデルコード]
    Output --> Routine[ビューとルーチン]
    
    Workspace -. クラウド同期 (Y.Doc) .-> Account[ユーザーアカウントとクラウドストレージ]
    Tabs -. 読み取り専用の共有を生成 .-> Share[読み取り専用の共有リンク]
    Share -. コピーとして保存 .-> Workspace
```

## 概念の説明

### 1. ワークスペース（Workspace）と複数タブ（Tabs）
- ワークスペースには、下書き、保存済みテーブル、フォルダーが含まれます。
- 同じワークスペースで、複数のタブにそれぞれ別のテーブルを開けます。タブを切り替えても、各タブの編集内容は失われません。
- タブを閉じても確認ダイアログは表示されません。編集中の内容は自動で下書きとして保存され、保存済みテーブルは上書きされません。

### 2. 下書きボックス（Drafts）
- 保存済みテーブルとしてまだ保存していない設計は、すべて下書きボックスにあります。
- タブバーの「下書きを作成」をクリックすると、複数の下書きを作成できます。下書きは左側の「ワークスペース」サイドバーの「下書き」グループに表示されます。下書きを使うと、保存済みテーブルに影響を与えずに別の案を試せます。

### 3. 保存済みテーブル（Saved Tables）、フォルダー、ゴミ箱
- 保存して名前を付けると、テーブルは保存済みテーブルになり、左側の「ワークスペース」サイドバーの「プロジェクト」に表示されます。ここで検索して開けます。
- フォルダーは入れ子にできます。テーブルやフォルダーをドラッグすると、分類を変更できます。
- 削除したテーブルはまず「ゴミ箱」に移動し、復元するか完全に削除するまで残ります。

### 4. 読み取り専用の共有（Share Link）とコピーの保存
- 上部の「共有」で生成されるリンクは読み取り専用です。リンクを開いた人は、あなたの設計を変更できません。
- 受け取った人は、バナーの「コピーとして保存して編集」をクリックすると、テーブル構造を自分のワークスペースに保存してから編集できます。

### 5. 出力の種類（DDL / DCL / ORM / ルーチン）
- **DDL（Data Definition Language）**：主キー、フィールド制約、コメント、インデックス、パーティション定義を含む `CREATE TABLE` 文を生成します。
- **DCL（Data Control Language）**：被付与者ごとに `GRANT SELECT` 文を生成します。
- **ORM モデルコード**：テーブル構造を Prisma、TypeORM、SQLAlchemy、GORM、JPA のモデルに変換します。
- **ビューとルーチン**：`CREATE VIEW` 文と、ストアドプロシージャ、関数、トリガーのコードの雛形を出力します。

### 6. ユーザーアカウントとクラウド同期
- サインインすると、ワークスペースはアカウントに紐付けられ、CRDT（Yjs Y.Doc）で同期されます。
- 下書き、保存済みテーブル、フォルダー、ゴミ箱は、バックグラウンドで差分同期されます。別のデバイスで同じアカウントにサインインすれば、編集を続けられます。
- 同期に手動の操作は不要です。編集内容はまずこのデバイス上のコピーに保存されます。オフラインでも編集を続けられ、ネットワークが復旧すると自動で同期されます。
- 「設定 > ワークスペースの同期」に現在の同期状態が表示されます。同期に失敗した場合は「同期を再試行」をクリックします。

### 7. AI 機能とクレジット
- AI 機能には「AIテーブルワークショップ」「AI編集」「AIインデックスアドバイザー」「AIレビュー」「AI SQL 解説」「AIのコメント」があります。
- AI 機能は、実際のトークン消費量に応じてクレジットを消費します。サインイン後、右上のアバターをクリックして「設定」を選び、「クレジット」で残高と利用履歴を確認できます。

## よくある質問

| 質問 | 回答 |
|---|---|
| 変更はどこに保存されますか？ | 保存していない変更は下書きボックスにあります。保存アイコンをクリックすると、テーブルは保存済みテーブルになります。 |
| 共有リンクの内容を他の人が変更できますか？ | できません。受け取った人はまず「コピーとして保存して編集」をクリックする必要があり、編集するのは自分のコピーです。 |
| 複数のデバイスはどう同期しますか？ | 同じアカウントでサインインすると自動で同期されます。手動のアップロードやダウンロードは不要です。 |
| パソコンを替えるとデータは消えますか？ | サインインしていない場合、データは現在のブラウザにだけ保存され、ブラウザのデータを消去すると失われます。サインインするとデータはクラウドに同期され、新しいパソコンで同じアカウントにサインインすれば表示されます。 |
| 削除したテーブルは元に戻せますか？ | 戻せます。削除したテーブルは「ゴミ箱」にあり、完全に削除するまでは「復元」できます。 |
