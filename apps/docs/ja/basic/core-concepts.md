# コアコンセプト

DDLBuilder のアーキテクチャと基本概念を理解することで、日々のテーブル設計、チーム共同作業、マルチデバイスでの作業をスムーズに行うことができます。

## アーキテクチャ概要

```mermaid
graph TD
    Workspace[ワークスペース Workspace] --> Tabs[マルチタブ管理 Tabs]
    Workspace --> Drafts[名前付き下書き Drafts]
    Workspace --> SavedTables[保存済みテーブル Saved Tables]
    SavedTables --> Folders[フォルダー分類 Folders]
    SavedTables --> Trash[ゴミ箱 Trash]
    
    Tabs --> Output[出力成果物]
    Output --> DDL[DDL 建表 / インデックス / パーティション]
    Output --> DCL[DCL 権限管理]
    Output --> ORM[ORM モデルコード]
    Output --> Routine[ビュー & Routine 雛形]
    
    Workspace -. リアルタイム同期 Y.Doc .-> Account[ユーザーアカウント & クラウド保存]
    Tabs -. 共有リンク生成 .-> Share[読み取り専用共有リンク]
    Share -. コピーを作成 .-> Workspace
```

---

## 主要概念の解説

### 1. ワークスペース（Workspace）とマルチタブ（Tabs）
- **ワークスペース**: 現在のセッションのトップレベルコンテナであり、作業中のすべてのテーブル定義、下書き、設定状態を保持します。
- **マルチタブ編集**: 同一ワークスペース内で複数の独立したテーブルを並行して設計できます。タブを切り替えても各テーブルの編集状態は保持されます。
- 未保存の変更があるタブを閉じる際は、意図しないデータ消失を防ぐため確認ダイアログが表示されます。

### 2. 下書き（Drafts）
- 名前を付けて保存していない一時的なテーブル設計は、デフォルトで**下書き**に保存されます。
- 左側のワークスペースサイドバーから**複数の名前付き下書き**を作成・管理できます。既存の確定テーブルを汚すことなく、新しい設計案を手軽に試作できます。

### 3. 保存済みテーブル（Saved Tables）、フォルダー、ゴミ箱
- **保存済みテーブル**: 保存操作によって生成される名前付きスナップショットです。サイドバードロワーからいつでも検索・読み込みできます。
- **フォルダー管理**: 業務ドメインやプロジェクトごとにフォルダー階層を作成し、ドラッグ＆ドロップで整理できます。
- **論理削除とゴミ箱**: テーブルを削除するとまずゴミ箱に移動され、一定期間保持されます。ワンクリックで復元でき、必要に応じて完全に削除できます。

### 4. 読み取り専用共有（Share Link）とコピー保存
- 上部の「共有リンク」から生成される URL は**完全に読み取り専用**であり、元の設計が第三者に直接変更される心配はありません。
- 共有リンクを開いた閲覧者は、バナーの**「コピーとして保存して編集」**をクリックすることで、自身のワークスペースに独立した編集可能コピーとして取り込めます。

### 5. 成果物出力体系（DDL / DCL / ORM / Routine）
- **DDL（データ定義言語）**: 主キー、カラム制約、コメント、インデックス、パーティション句を含む完全な `CREATE TABLE` 文を出力します。
- **DCL（データ制御言語）**: 権限付与の `GRANT` 文を自動生成し、テーブル作成と権限設定の乖離を防ぎます。
- **ORM モデルコード**: Prisma、TypeORM、SQLAlchemy、GORM、JPA などのフレームワークに応じた型付きモデルコードを生成します。
- **ビューと Routine**: `CREATE VIEW` 文およびストアドプロシージャ・関数・トリガーの骨格コードを出力します。

### 6. ユーザーアカウントと CRDT リアルタイムクラウド同期
- ログインすると、ワークスペースはアカウントと紐づけられ、**CRDT（Yjs Y.Doc）**を基盤としたリアルタイム同期が行われます。
- 下書き、保存済みテーブル、フォルダー、ゴミ箱の状態が**バックグラウンドで自動的に増分同期**され、複数デバイス間でのシームレスな移行が可能です。
- 設定画面には「今すぐ同期」「クラウドへ同期」「クラウドからダウンロード」ツールが用意されており、万一の同期競合時にも詳細を確認できます。

### 7. AI クレジットセンターと高度な AI 機能
- DDLBuilder は多彩な AI 支援（マスター建表工房、AI テーブル変更、AI インデックスアドバイザー、DDL 構造レビュー、SQL 解説、スマートコメント生成）を備えています。
- AI 機能は実際のトークン消費量に基づいてクレジットを消費します。残高や利用履歴はプロフィールの「クレジットセンター」から確認できます。

## 疑問と確認の早見表

| 状況 / 疑問 | 正しい理解と対処 |
|---|---|
| **変更内容はどこに保存されるか？** | 一時的な作業は下書きに保持されます。確定版は保存アイコンを押して「保存済みテーブル」にしてください。 |
| **共有リンクから他人に改変されないか？** | 改変されません。共有リンクは読み取り専用で、編集にはコピーの作成が必要です。 |
| **複数端末で同期するには？** | 同一アカウントでログインすると、バックグラウンドでリアルタイムに自動増分同期されます。 |
| **端末を変更するとデータは消えるか？** | 未ログイン時はブラウザ内にのみ保存されます。クラウド保存にはログインをご利用ください。 |
| **削除したテーブルは復元できるか？** | 可能です。削除したテーブルはゴミ箱に保管され、ゴミ箱を空にする前であればいつでも復元できます。 |
