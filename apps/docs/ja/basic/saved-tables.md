# 保存済みテーブルと下書き

このページでは、保存済みテーブル、フォルダー、ゴミ箱、下書き、クラウド同期について説明します。

## 利用場面

複数のプロジェクトのテーブルを同時に管理する場合、業務モジュールごとにテーブルを分類する場合、複数のデバイスで編集を続ける場合に使います。

---

## 操作ガイド

### 1. 保存済みテーブルを保存して開く
- テーブル設定エリアの保存アイコン（ツールチップは「現在のテーブルを保存する」）をクリックし、名前を入力します。保存したテーブルは、左側の「ワークスペース」サイドバーの「プロジェクト」に表示されます。
- サイドバーの検索ボックスに名前またはデータベースの種類を入力すると、一覧を絞り込めます。
- 一覧のテーブルをクリックすると、そのフィールド、インデックス、スキーマ名が新しいタブで開きます。すでに開いているテーブルの場合は、そのタブに切り替わります。
- 名前を変更するには、テーブルの「その他の操作」メニューで「名前の変更」を選びます。開いているテーブルを変更して再度保存すると、元の記録が上書きされます。

### 2. フォルダーでグループ分けする
- サイドバーの検索ボックスの横にある「フォルダーの作成」（+）をクリックし、業務領域ごとにフォルダーを作成します（例：`ユーザー管理`、`取引決済`）。
- テーブルをフォルダーにドラッグして分類するか、フォルダーをドラッグして階層を変更します。

### 3. ゴミ箱
- テーブルのメニューで「削除」をクリックし、「ゴミ箱に移動」で確定すると、テーブルはゴミ箱に移動します。
- サイドバー下部の「ゴミ箱」をクリックし、項目のメニューで「復元」を選ぶと、テーブルは「プロジェクト」の一覧に戻ります。
- 「完全に削除」を選ぶと、その項目だけを削除します。「ゴミ箱を空にする」をクリックすると、ゴミ箱を空にします。空にした後は元に戻せません。

### 4. 複数の下書き
- 保存済みテーブルとしてまだ保存していない設計は、下書きボックスに入っています。
- タブバーの「下書きを作成」をクリックすると、新しい下書きを作成できます。左側の「ワークスペース」サイドバーの「下書き」グループにすべての下書きが表示され、クリックすると切り替わります。下書きは保存済みテーブルに影響しません。

### 5. アカウントへのサインインとクラウド同期
- **自動の差分同期**：サインインすると、下書き、保存済みテーブル、フォルダー、ゴミ箱は Y.Doc によって自動でクラウドに差分同期されます。
- **ローカル優先とオフライン利用**：サインイン済みのデバイスでページを開くと、まずこのデバイス上のコピーを読み込みます。オフラインでも編集を続けられ、変更はこのデバイスに保存されます。ネットワークが復旧すると自動で同期されます。
- **同期状態の確認**：上部のバーと「設定 > ワークスペースの同期」に現在の同期状態が表示されます。同期に失敗した場合は「同期を再試行」をクリックします。手動でアップロードやダウンロードをする必要はありません。
- **サインイン前のデータをアカウントに移す**：サインイン後、アカウントのワークスペースが空で、現在のブラウザにサインインせずに作成したデータがある場合は、「ローカルワークスペースの移行」が表示されます。移行でアカウントの内容が上書きされることはありません。アカウントに同じ項目があり内容が異なる場合、このデバイスの項目は「(Imported)」が付いたコピーとして別に保存されます。内容が同じ場合はスキップされます。「後で」を選ぶこともできます。移行後も、このデバイスにあるサインイン前のデータは残ります。
- **サインアウト**：サインアウトの前に、このデバイスの変更がクラウドで保存済みと確認されるまで待ちます。確認できない場合はサインアウトを取り消し、ローカルのデータを残します。同期が回復してから再試行してください。サインアウトに成功すると、このデバイス上にあるそのアカウントのワークスペースのコピーが削除されます。

## 確認と完了の目安

- [ ] よく使うテーブルに名前を付けて保存し、「ワークスペース」サイドバーで検索して開ける。
- [ ] テーブルが業務ごとにフォルダーに分類されている。
- [ ] アカウントにサインインした後、他のブラウザやデバイスで開くと、同じフォルダーとテーブルの一覧が表示される。
- [ ] 誤って削除したテーブルを「ゴミ箱」から復元できる。

## 注意事項

- 下書きは一時的な試作に向いています。残したいバージョンは、手動で保存済みテーブルとして保存してください。
- サインインしていない場合、データは現在のブラウザにだけ保存され、ブラウザのサイトデータを消去すると失われます。サインインすると、データはクラウドに同期されます。
