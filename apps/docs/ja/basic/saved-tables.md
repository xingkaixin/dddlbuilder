# 保存済みテーブルと下書き

このガイドでは、保存済みテーブルのスナップショット管理、フォルダーによる分類、ゴミ箱機能による復元、複数の名前付き下書き、および複数デバイス間でのクラウド同期について解説します。

## 概要

複数プロジェクトのテーブル構造を長期的に管理・蓄積し、業務モジュールごとに整理したり、複数の作業端末間で設計データをシームレスに同期・活用できます。

---

## 主な操作手順

### 1. 名前付きテーブルの保存と読み込み
- **テーブルの保存**: テーブル設定エリアの保存アイコンをクリックして名前を入力すると、現在のテーブル構造が「保存済みテーブル」にスナップショットとして保存されます。
- **検索とフィルタリング**: 「保存済みテーブル」ドロワーを開き、テーブル名、日本語名、データベースタイプでリアルタイムに絞り込み検索ができます。
- **ワークスペースへの読み込み**: 一覧内のテーブルをクリックすると、現在のアクティブタブに展開され、フィールド、インデックス、Schema Name が完全に復元されます。
- **名前変更と上書き更新**: メニューから直接テーブル名を変更できます。読み込み済みのテーブルを編集した後は、保存ボタンから直接上書き保存が可能です。

### 2. フォルダーによるグループ整理
- **新規フォルダー作成**: ドロワー内で「新規フォルダー」をクリックし、業務ドメイン（例: `認証基盤`、`決済モジュール`）ごとにフォルダーを作成します。
- **ドラッグ＆ドロップ整理**: テーブルを目的のフォルダーへドラッグしたり、フォルダーの階層構造を自由に調整してワークスペースを整理できます。

### 3. 論理削除とゴミ箱の安全設計
- **安全な削除**: メニューから「削除」を選択すると、テーブルは**ゴミ箱**へ移動され、誤操作による即時消失を防ぎます。
- **ワンクリック復元**: ゴミ箱タブを開き、「復元」をクリックすると、保存済みテーブル一覧へ即座に戻すことができます。
- **完全削除**: ゴミ箱内の「ゴミ箱を空にする」を実行すると、データが恒久的に消去されます。

### 4. サイドバーでの複数下書き並行管理
- 正式に保存していない一時的な設計は**下書き**として保持されます。
- 左側のサイドバーから**複数の名前付き下書き**を作成・切り替えることができ、確定済みのテーブルに影響を与えることなく新しいアイデアを自由に試作できます。

### 5. アカウントログインとリアルタイムクラウド同期
- **自動増分同期**: ログインすると、下書き、保存済みテーブル、フォルダー、ゴミ箱がアカウントに紐づけられ、Y.Doc による**リアルタイム自動増分同期**が有効になります。
- **ローカルファーストとオフライン利用**: ログイン済み端末では、まずローカルコピーからページを開きます。オフラインでも編集を続けられ、変更はローカルに保存され、ネットワーク復旧後に自動で同期されます。
- **同期状態の確認**: ヘッダーと「設定 > ワークスペースの同期」に現在の同期状態が表示されます。同期に失敗した場合は「同期を再試行します」をクリックします。手動のアップロードやダウンロードは不要です。
- **未ログイン時のデータをアカウントへ移行**: ログイン後、アカウントのワークスペースが空で、このブラウザに未ログイン時に作成したデータがある場合、「ローカルワークスペースを移行する」の案内が表示されます。移行でアカウントの内容が上書きされることはありません。アカウントに同じ項目があり内容が異なる場合、ローカル側の項目は「(Imported)」付きのコピーとして保存されます。内容が同じ場合はスキップされます。「後で」を選ぶこともできます。移行後も、このブラウザの未ログイン時のデータは残ります。
- **ログアウト**: ログアウト前に、ローカルの変更がクラウドに保存されたことを確認するまで待ちます。確認できない場合はログアウトを中止し、ローカルデータを保持します。同期を復旧してから再試行してください。ログアウトに成功すると、この端末にあるそのアカウントのワークスペースのコピーは削除されます。

## 完了のチェックリスト

- [ ] 主要なテーブルが名前を付けて保存され、ドロワーからすばやく検索・読み込みできる。
- [ ] 関連テーブルがフォルダーに適切に分類されている。
- [ ] アカウントにログイン後、別端末やブラウザでも同じフォルダーとテーブルが自動復元される。
- [ ] 誤って削除したテーブルをゴミ箱から問題なく復元できる。

## 注意事項

- **下書きと保存済みテーブルの使い分け**: 下書きは一時的な作業用です。重要な設計マイルストーンでは必ず名前を付けて「保存済みテーブル」に保存してください。
- **未ログイン時のデータ保持**: 未ログイン時のデータはブラウザのローカルストレージにのみ保存されます。キャッシュ消去によるデータ消失を防ぐため、ログインしてクラウド保存することをお勧めします。
