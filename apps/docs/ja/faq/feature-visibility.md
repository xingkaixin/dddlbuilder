# 機能の場所と表示条件

このページでは、一部のタブ、ボタン、入口がどこにあり、どの条件で表示されるかを説明します。

---

## 1. 「パーティショニング」や「シャーディング」タブが表示されないのはなぜですか？

- 「パーティショニング」は、データベースの種類が MySQL 系（MySQL、MariaDB、TiDB、OceanBase (MySQL)、GBase、PolarDB）の場合にだけ表示されます。PostgreSQL、Oracle などのほかの種類では表示されません。
- 「シャーディング」は、データベースの種類が **PostgreSQL (Citus)** の場合にだけ表示されます。参照表と分散テーブルの設定に使います。通常の PostgreSQL では表示されません。
- どちらも設定エリアの「詳細設定」メニューにあり、メインのタブバーにはありません。

---

## 2. 「外部キー」や「ER図」が表示されないのはなぜですか？

- 「外部キー」タブは、テーブルの設定エリアにあります。データベースの種類が Hive の場合や、オブジェクトの種類がビューの場合は、このタブは表示されません。現在のテーブルにフィールドがまだない場合、パネルに「最初にフィールドを追加してください」と表示されます。
- 「ER図」は、テーブル設定エリアの「その他」メニューにあります。ER 図には保存済みのテーブルだけが表示されます。図の中で線を結びたいテーブルは、先に保存してください。

---

## 3. 生成結果に「ORM」や「ルーチン」が見つからないのはなぜですか？

- 生成結果の上部のタブバーには「DDL」「DCL」「ORM」「ルーチン」があります。タブバーが見えない場合は、出力パネルが折りたたまれていないか確認してください。
- データベースの種類が SQLite / D1 の場合、「DCL」と「ルーチン」は表示されません。
- ビューの DDL は「DDL」タブに表示されます。ビュー専用のタブはありません。

---

## 4. 「スキーマの変更を表示する」が表示されないのはなぜですか？

「スキーマの変更を表示する」はテーブル設定エリアの「その他」メニューにあり、次の条件をすべて満たすときに表示されます。

1. 現在のタブに読み込まれているのが**保存済みテーブル**で、新しく作成した空の下書きではない。
2. そのテーブルに**実際の構造変更**を加えている。たとえばフィールドの追加・削除、型の変更、インデックスの変更です。

変更していないテーブルと、一度も保存していない下書きには比較するバージョンがないため、この項目は表示されません。

---

## 5. 「AIレビュー」が使えない、または AI 機能を開始できないのはなぜですか？

- 「DDL」にまだ文が生成されておらず、「-- 左側にテーブル情報を入力してください」のような案内だけが表示されている場合、「AIレビュー」ボタンは使えません。データベースの種類が SQLite / D1 の場合も使えません。
- AIテーブルワークショップ、AI編集、AIインデックスアドバイザー、AIレビューは、大規模言語モデルのサービスを呼び出します。サインインしていて、アカウントのクレジット残高が 0 より大きい必要があります。

---

## 6. 「ゴミ箱」が見つからないのはなぜですか？

- ゴミ箱は、左側の「ワークスペース」サイドバーの下部にあります。サイドバーが折りたたまれている場合は、先に展開してください。
- ゴミ箱に移動したテーブルはここに保管されます。1 件ずつ「復元」または「完全に削除」でき、「ゴミ箱を空にする」もできます。
