# 共有と共同作業

このページでは、共有リンク、編集可能なコピー、下書きに関するよくある質問に答えます。

---

## 1. 共有リンクで開いたページを直接編集できないのはなぜですか？

- 共有リンクで開くのは読み取り専用のスナップショットです。受け取った人は直接変更できず、共有した人の元のテーブルも変わりません。
- 変更する場合は、次の手順で進めます。
  1. 共有ページ上部のバナーで **コピーとして保存して編集** をクリックします。
  2. DDLBuilder はこのテーブル構造を、自分のワークスペースにコピーとして保存します。その後ホームページに戻り、コピーを自動で読み込みます。
  3. コピーと元の共有リンクは互いに独立しています。コピーを変更、保存しても、新しい DDL を生成しても、元の共有リンクには影響しません。

---

## 2. 共有リンクを開くとすぐにホームページへリダイレクトされるのはなぜですか？

- 共有リンクの有効期限は 7 日間で、期限が切れると自動的に無効になります。
- WeChat、DingTalk などのチャットツールで送ると、リンクが改行されたり途中で切れたりすることがあります。リンク末尾の共有 ID が欠けていると、リンクが存在しないと表示され、ホームページに戻ります。
- 共有した人に元のテーブルを開き直してもらい、「共有」をクリックして新しい URL を生成し、URL 全体をコピーして送ってもらってください。

---

## 3. テーブル構造を変更していないとき、「共有」を何度クリックしても同じ URL になるのはなぜですか？

- ブラウザは、最後に生成した共有リンクと、そのときのテーブル構造の署名を記憶しています。もう一度「共有」をクリックしたとき、テーブル構造の署名が同じでリンクの期限が切れていなければ、DDLBuilder はそのリンクをそのままコピーし、「既存のリンクを再利用」と表示します。新しい共有は作成しません。
- 新しいリンクが必要な場合は、先にテーブル構造を変更してから（フィールドの追加やコメントの更新など）、「共有」をクリックしてください。

---

## 4. 下書き（Drafts）と保存済みテーブル（Saved Tables）は、共同作業でどう違いますか？

| 項目 | 下書き（Drafts） | 保存済みテーブル（Saved Tables） |
|---|---|---|
| **用途** | 自動保存される一時的な設計で、構造はまだ調整中 | 名前を付けて手動で保存したテーブル |
| **バージョンと履歴** | 最新の状態だけを保持し、バージョン比較はできない | 保存のたびにスナップショットを作成し、バージョン履歴とタイムライン再生に対応 |
| **フォルダー管理** | サイドバーの下書き一覧に表示される | サイドバーでフォルダーを作成し、ドラッグで分類できる |
| **共有** | 名前を付けて保存してから共有することを推奨 | いつでも読み取り専用の共有リンクを生成し、チームのレビューに使える |
