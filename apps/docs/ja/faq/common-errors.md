# エラーと失敗への対処

このページでは、DDLBuilder の利用中に発生しやすい一般的なエラー、異常事態、およびそのトラブルシューティング手順をまとめています。

---

## 1. 共有リンクが開けない・有効期限切れの警告

### 現象
共有リンクを開いた際に「共有リンクが存在しないか有効期限が切れています」と表示され、トップページにリダイレクトされる。

### 対処手順
1. **URL の完全性を確認**: チャットツール（Slack、Teams、LINE 等）による URL の途切れや余計な文字の混入がないか確認し、完全な URL をブラウザのアドレスバーに直接貼り付けて開きます。
2. **有効期限の確認**: 共有リンクには有効期限（通常 7 日間）が設定されています。期限が切れている場合は、共有元に再発行を依頼してください。
3. **リンクの再発行**: 共有元のユーザーは、対象のテーブルを開いて上部の「共有リンク」を再クリックし、新しい URL を発行・送信します。

---

## 2. SQL インポートの失敗または解析漏れ

### 現象
- 検証ステップで「SQL 解析失敗」または構文エラーが表示される。
- インポート後に一部のカラム、インデックス、権限設定が反映されない。

### 対処手順
1. **方言の一致を確認**: インポートダイアログの「インポート元データベース」が、SQL スクリプトの実際の構文（MySQL、Oracle、PostgreSQL 等）と一致しているか確認します。
2. **コアの CREATE TABLE に絞り込む**: まず最も基本的な `CREATE TABLE` 文のみをインポートし、主構造が正常に認識されるか確認します。
3. **長大なスクリプトの分割**: トリガーやプロシージャを含む長大なスクリプトは、分割して少しずつインポートすることでエラー箇所を特定しやすくなります。
4. **非標準クライアント構文の除去**: `USE database;` や `SET NAMES utf8mb4;` などのクライアント専用コマンドは除外してからインポートしてください。

## 3. AI 機能のリクエスト失敗（生成・変更・レビュー・解説）

### 現象
- 「マスター建表工房」で生成がタイムアウトまたはエラーになる。
- 「マスターレビュー」や「選択範囲を解説」が応答しない。

### 対処手順
1. **一時的な通信エラー**: ページを再読み込み（リロード）して再試行します。
2. **プロンプトの細分化**: 一度の指示で数十個のテーブルを一括生成させず、「基本カラム作成 → インデックス追加 → 制約調整」の順で段階的に対話を進めます。
3. **AI クレジット残高の確認**: 右上アイコンの「設定 > クレジットセンター」でアカウントの残高を確認します。残高不足の場合はクレジットを補充してください。

---

## 4. ログインおよびワークスペース同期の異常

### 現象
- ログイン時に「メールアドレスが未検証です」または「リクエストが多すぎます」と表示される。
- ワークスペース同期で「同期失敗」または競合警告が表示される。

### 対処手順
1. **メール検証リンクのクリック**: 登録時のメールボックス（迷惑メールフォルダ含む）を確認し、認証リンクをクリックしてアカウントを有効化します。
2. **レート制限の待機**: 「リクエストが多すぎます」と表示された場合は、セキュリティ保護のため 1〜2 分待ってから再試行してください。
3. **手動同期の実行**: 「設定 > ワークスペース同期」を開き、「今すぐ同期」をクリックして状態を更新します。複数端末間で競合がある場合は詳細を確認してください。

---

## 5. クリップボードへのコピー失敗

### 現象
「DDL コピー」や「DCL コピー」をクリックした際に「コピーに失敗しました」と表示される。

### 対処手順
1. **ブラウザの権限設定**: ブラウザのアドレスバー付近から、当サイトに対するクリップボードへの書き込み権限が許可されているか確認します。
2. **ショートカットキーによる手動コピー**: 制限された環境（リモートデスクトップ等）では、右側コードエリア内のテキストをマウスで全選択し、`Ctrl+C`（または `Cmd+C`）で手動コピーしてください。
