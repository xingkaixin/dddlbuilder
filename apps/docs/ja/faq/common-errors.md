# エラーと障害の処理

## 共有リンクは使用できません

### 症状

共有リンクを開くと、「共有リンクが見つからないか期限切れです」と表示され、ホームにリダイレクトされます。

### 簡単なチェック

- リンクが 7 日より古いかどうか。
- リンクが切り詰められているか、余分な文字が含まれているかどうか。

### ステップ

1. 元のリンク全体をコピーして、再度開きます。結果: これにより、チャット ツールによるリンクの切り捨てが排除されます。
2. それでも失敗する場合は、現在のテーブルに戻り、`Share` を再度クリックします。結果: システムは有効なリンクを生成し、それをクリップボードにコピーします。
3. 新しいリンクを共同編集者に送信し、再試行するよう依頼します。結果: ほとんどの有効期限または無効化の問題が解決されました。

### まだ解決していない場合

まず、同じネットワーク環境で自分で新しいリンクを開きます。ローカルでも失敗する場合は、時間とページ メッセージの詳細を添えて製品サポートに連絡してください。

## SQL インポートの失敗または異常な結果

### 症状

- 検証中に「SQL 解析に失敗しました」と表示されます。
- インポート後、フィールド、インデックス、または被付与者が不完全です。

### 簡単なチェック

- SQL が空か長すぎるか。
- `Source Database` が SQL 言語と一致するかどうか。

### ステップ

1. インポートダイアログで、`Source Database` が正しいことを確認します。結果: システムはターゲットの方言で再解析します。
2. 最初にコアの `CREATE TABLE` ステートメントをインポートします。結果: 主構造が最初に認識されます。
3. 次に、`CREATE INDEX`、`ALTER TABLE`、および `GRANT` を段階的に追加します。結果: どのセグメントが問題を引き起こしているのかをすぐに特定できます。
4. SQL が非常に長い場合は、分割してバッチでインポートします。結果: これにより、大きすぎるテキストによる検証エラーが回避されます。

### まだ解決していない場合

再現可能な最小限の SQL セグメントと選択したデータベース タイプを保持してから、製品サポートに送信してください。

## AI リクエストが失敗しました (生成、レビュー、説明)

### 症状

- AI テーブル ワークショップの生成に失敗します。
- AI レビューは失敗します。
- 説明の選択が失敗します。

### 簡単なチェック

- これが短期的なネットワークジッターであるかどうか。
- AI リクエストが短期間にあまりにも頻繁にトリガーされるかどうか。

### ステップ

1. ページを更新し、同じ操作を 1 回再試行します。結果: これにより、一時的なセッションの異常が排除されます。
2. 1 つの長いリクエストを複数の短いリクエストに分割します。結果: 通常、成功率が高くなります。
3. ピーク時間外に再試行します。結果: これにより、サービスの輻輳によって引き起こされる障害が減少します。

### まだ解決していない場合

失敗したアクション名 (生成/レビュー/説明) とトリガー時間を記録し、製品サポートに連絡してください。

## サインインまたは同期に失敗しました

### 症状

- サインインに「電子メールが検証されていません」、「電子メールまたはパスワードが無効です」、または「要求が多すぎます」と表示される。
- ワークスペースの同期に「同期に失敗しました」と表示される。
- AI 機能が「クレジットが不足しています」と表示します。

### 簡単なチェック

・メールアドレスとパスワードが正しいかどうか。
- 現在のネットワークが安定しているかどうか。
- サインインまたは同期が短期間に何度も試行されたかどうか。

### ステップ

1. 電子メールとパスワードを再確認して、再試行します。結果: これにより入力エラーが排除されます。
2. 「メールが検証されていません」と表示された場合は、受信トレイ (スパムを含む) を確認し、検証リンクをクリックします。結果: 検証後、正常にサインインできます。
3. 「リクエストが多すぎます」と表示された場合は、1 ～ 2 分待ってから再試行します。結果: これにより、レート制限保護がバイパスされます。
4. 同期が失敗した場合は、ページを更新してまだサインインしていることを確認し、アップロードまたはダウンロードを再試行します。結果: これにより、期限切れのセッションが除外されます。
5. AI 機能がクレジット不足を報告した場合は、[設定] を開いて [クレジット] タブの使用履歴を確認します。結果：残高と内訳を確認できます。チャンネルが開いたら充電します。

### まだ解決していない場合

正確なエラー メッセージ、動作時間、ネットワーク環境を記録し、製品サポートに連絡してください。

## コピーに失敗しました

### 症状

`Copy DDL` または `Copy DCL` をクリックすると、「コピーに失敗しました。もう一度お試しください。」と表示されます。

### 簡単なチェック

- 現在のブラウザでクリップボードのアクセス許可がブロックされているかどうか。
- 制限された環境にいるかどうか (リモート デスクトップまたは管理ブラウザ ポリシー)。

### ステップ

1. コピーボタンを一度押してください。結果: これにより、時折発生する失敗が排除されます。
2. それでも失敗する場合は、右側の SQL テキストを手動で選択し、システム コピーのショートカットを使用します。結果: プロセスをブロックすることなく配信が続行されます。
3. 必要に応じて、一般的に使用されるブラウザに切り替えて、再度コピーします。結果: これにより、現在のブラウザーのポリシー制限が回避されます。

### まだ解決していない場合

作業環境でクリップボードへのアクセスが制限されているかどうかを確認し、必要に応じて地域の IT 管理者に問い合わせてください。
