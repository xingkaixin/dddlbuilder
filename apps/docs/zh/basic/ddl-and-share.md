# DDL 输出与分享

本指南介绍如何审查、导出建表 DDL、DCL 权限语句、ORM 模型及 Routine 代码，并通过只读链接与团队成员安全协作。

## 适用场景

适用于完成表结构建模后，将产物交付给数据库评审、录入上线工单、嵌入业务工程代码，或生成协作链接供同事审阅。

---

## 核心操作指引

### 1. 审查与切换多类型产物
在右侧输出面板中，可自由切换以下产物视图：
- **建表 DDL**：审查完整的 `CREATE TABLE` 语句、主键、字段约束、注释、索引及分区语法。若配置了 `Schema Name`，表名会自动以 `schema.table` 输出。
- **授权 DCL**：检查针对目标用户或角色的 `GRANT` 权限语句。
- **ORM 模型代码**：支持在 **Prisma、TypeORM、SQLAlchemy、GORM、JPA** 五种主流框架间一键切换，获取对应的类型映射与注解定义。
- **视图/Routine**：查看配置的 `CREATE VIEW` 语句或存储过程、函数、触发器代码骨架。

### 2. 代码复制与格式化
- 点击对应面板中的**复制DDL**、**复制DCL**、**复制ORM**或**复制视图/Routine**，一键写入剪贴板。
- 支持在工具栏切换**紧凑 / 对齐**格式显示，复制结果会与当前预览的高可读性格式保持一致。

### 3. 折叠面板以扩展编辑视野
当表格字段较多需要宽屏横向滚动时，点击输出面板顶部的**折叠按钮**收起右侧面板；需要查看代码时点击展开即可，布局平滑自适应。

### 4. 生成只读分享链接
1. 点击顶部操作栏的**分享链接**按钮。
2. 系统自动生成带有时间有效期的**只读分享 URL** 并复制到剪贴板。
3. 分享内容完整保留当前的表名、Schema Name、字段约束、索引与杂项配置。

### 5. 协作方接收与副本分支
- 协作成员打开分享链接后，页面处于**只读保护状态**，无法直接篡改原始设计。
- 如需在此基础上修改或二次演进，点击顶部横幅中的**保存为副本并开始编辑**，系统将自动在成员的个人工作区中创建一份可编辑副本。

## 数据库版本与特殊对象范围

::: info 数据库方言细节说明
- **Oracle 同义词**：建表 DDL 不再自动追加 `PUBLIC SYNONYM`。如业务需要同义词，请由具备权限的 DBA 单独创建。
- **MySQL 复杂默认值**：对于 TEXT、BLOB、JSON 等类型使用常量默认值时，系统输出表达式语法（如 `DEFAULT ('{}')`），需要 MySQL 8.0.13 或更高版本。
- **转义行为**：MySQL 系字符串默认按启用反斜杠转义模式输出。若目标会话开启了 `NO_BACKSLASH_ESCAPES`，执行前需核实转义语义。
:::

## 校验与完成标志

- [ ] 复制的 SQL 或 ORM 代码粘贴至目标客户端可正常运行或编译。
- [ ] 若配置了命名空间，产物中的表名均正确保持为限定名称。
- [ ] 分享链接在无痕窗口或他人电脑上可正常打开且为只读视图。
- [ ] 点击“保存为副本”能顺利进入首页工作区并正常编辑。
