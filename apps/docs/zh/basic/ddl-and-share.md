# DDL 输出与分享

本页介绍如何查看和复制建表 DDL、授权 DCL、ORM 模型与程序单元代码，以及如何用只读链接分享表结构。

## 适用场景

适用于表结构设计完成后，把 SQL 交给数据库评审或上线工单，把 ORM 代码放进业务项目，或发链接给同事查看。

---

## 核心操作指引

### 1. 查看各类输出
「生成结果」中有以下标签页：
- 「建表 DDL」：`CREATE TABLE` 语句，包含主键、字段约束、注释、索引和分区。填写了「Schema Name」时，表名输出为 `schema.table`。
- 「授权 DCL」：每个授权对象的 `GRANT SELECT` 语句。
- 「ORM 模型」：在「ORM 框架」中选择 Prisma、TypeORM、SQLAlchemy、GORM 或 JPA，生成对应的模型代码。
- 「程序单元」：存储过程、函数和触发器的代码骨架。对象类型为视图时，`CREATE VIEW` 语句显示在「建表 DDL」中。

### 2. 代码复制与格式化
- 点击各标签页中的「复制DDL」「复制DCL」「复制ORM代码」或「复制程序」，代码会复制到剪贴板。
- 「建表 DDL」可以在「紧凑」和「对齐」两种格式间切换，复制的内容与当前显示的格式一致。

### 3. 切换设计区与生成结果
打开标签栏右侧的「分屏预览」后，设计区在上，生成结果在下。字段较多时，点击生成结果顶部的「收起输出面板」，只保留设计区；需要看代码时点击「生成结果」。

### 4. 生成只读分享链接
1. 点击顶部的「分享链接」。
2. 筑表师生成只读链接并复制到剪贴板，链接有效期 7 天。
3. 链接包含当前表的表名、Schema Name、字段、约束、索引和杂项配置。

### 5. 接收方保存副本
- 通过分享链接打开的页面是只读的，不能直接修改。
- 需要修改时，点击顶部提示条中的「保存为副本并开始编辑」。筑表师把副本保存到接收方自己的工作区并打开，之后编辑的是这份副本。

## 数据库版本与特殊对象范围

::: info 数据库方言细节说明
- **Oracle 同义词**：建表 DDL 不再自动追加 `PUBLIC SYNONYM`。如业务需要同义词，请由具备权限的 DBA 单独创建。
- **MySQL 复杂默认值**：对于 TEXT、BLOB、JSON 等类型使用常量默认值时，系统输出表达式语法（如 `DEFAULT ('{}')`），需要 MySQL 8.0.13 或更高版本。
- **转义行为**：MySQL 系字符串默认按启用反斜杠转义模式输出。若目标会话开启了 `NO_BACKSLASH_ESCAPES`，执行前需核实转义语义。
:::

## 校验与完成标志

- [ ] 复制的 SQL 或 ORM 代码粘贴至目标客户端可正常运行或编译。
- [ ] 填写了「Schema Name」时，所有输出中的表名都带 schema 前缀。
- [ ] 分享链接在无痕窗口或他人电脑上能打开，且为只读。
- [ ] 点击「保存为副本并开始编辑」后，副本在工作区中打开并可以编辑。
