# 在线生成 MySQL、PostgreSQL 建表语句

在[筑表师中开始设计](https://ddl.xingkaixin.me/)，按下面的步骤完成第一张表。已有 SQL 时，可直接使用[导入与解析 SQL](/zh/advanced/import-and-parse)。

## 示例：生成一张 MySQL 用户表

目标是创建用户表：`id` 是主键，`email` 必填且唯一，`display_name` 可以为空。下面的 SQL 可以直接作为导入示例。

```sql
CREATE TABLE user_account (
  id INT NOT NULL,
  email VARCHAR(255) NOT NULL,
  display_name VARCHAR(100),
  PRIMARY KEY (id)
);
CREATE UNIQUE INDEX uk_user_account_email ON user_account (email);
```

1. 打开[筑表师](https://ddl.xingkaixin.me/)，点击顶部「导入结构」，「来源类型」选择 SQL，「源数据库」选择 MySQL，然后粘贴示例。
2. 确认预览包含三个字段、`id` 主键和 `email` 唯一索引，再导入表结构。
3. 将 `display_name` 长度改成 `150`，在「生成结果」的「建表 DDL」中确认已变为 `VARCHAR(150)`，然后复制 SQL。

导出后的排版、标识符引号或索引语句位置可能不同。核对字段类型、可空性、主键和唯一索引的语义即可。切换目标数据库后仍需核对类型与默认值的兼容性；工具不会替你连接数据库执行 SQL。

需要多表关系时继续[SQL 转 ER 图](/zh/advanced/foreign-key-and-er)，需要应用代码时继续[SQL 转 ORM 模型](/zh/advanced/orm-generation)。

## 适用场景

在界面中配置表结构，筑表师按所选数据库实时生成建表 DDL、授权 DCL、ORM 模型代码，以及视图和程序单元的 SQL，不需要为每种数据库手写 SQL。

## 核心操作流程

### 1. 设置数据库方言与基础信息
- 在表配置区域选择「数据库类型」（如 MySQL、PostgreSQL、Oracle、TiDB）。
- 填写「表名」（如 `user_account`）和「表中文名」（如 `用户账户表`）。
- 数据库支持命名空间时（如 PostgreSQL、Oracle、SQL Server），可以在「表属性」中填写「Schema Name」（可选），生成的 SQL 会使用 `schema.table` 形式的表名。

::: tip 表名填写规范
「表名」只填表名本身。需要命名空间时填写「Schema Name」，不要在表名里写 `schema.table`。
:::

### 2. 配置字段列表与约束
- 在「字段配置」表格中逐行填写「字段名」「字段中文名」和「字段类型」。
- 按需设置「是否为空」（`NOT NULL` / `NULL`）、「默认类型」（如常量、当前时间、uuid）和「默认值」。
- 「生成结果」中的「建表 DDL」随输入实时更新。

### 3. 补充索引、权限与高级配置
- 在「索引配置」标签页添加主键、唯一索引或普通索引，一个索引可以包含多个字段。
- 在「授权配置」标签页添加用户或角色，生成 `GRANT` 授权语句（DCL）。
- 在「杂项设置」标签页设置存储引擎、字符集、排序规则或表空间。

### 4. 套用整表蓝本（可选）
整表蓝本是你自己保存的表结构，筑表师没有内置蓝本。在「字段配置」工具栏点击「整表蓝本」，选择一个蓝本并点击「应用蓝本」，筑表师会新开一个草稿标签页，载入蓝本的字段、索引、数据库类型和表级配置。新标签页沿用当前表的表名、表中文名、Schema Name 和授权对象，不带外键。

还没有蓝本时，在同一菜单中选择「将当前表保存为蓝本...」。蓝本保存在当前浏览器中。

### 5. 逆向导入已有结构（可选）
已有 SQL 或表结构文件时，点击顶部「导入结构」，「来源类型」可选 SQL、CSV / TSV、Excel 或 JSON Schema / OpenAPI。筑表师解析出字段、类型和索引后填入工作区。

### 6. 复制与导出产物
- 在「生成结果」中点击「复制DDL」或「复制DCL」，再粘贴到数据库客户端或工单系统。
- 切换到「ORM 模型」标签页，生成 Prisma、TypeORM、SQLAlchemy、GORM 或 JPA 模型代码。
- 切换到「程序单元」标签页，生成存储过程、函数和触发器的代码骨架。对象类型为视图时，`CREATE VIEW` 语句显示在「建表 DDL」中。

### 7. 保存与多标签管理
- 点击表配置区域的保存图标（提示为「保存当前表」）并命名。保存后，这张表出现在左侧「工作区」侧边栏的「项目」中，之后可以从这里打开，或在表配置区域查看「历史版本」。
- 工作区可以同时打开多个标签页，每个标签页编辑一张表。

## 注册与邮箱验证（可选）

本地建模无需登录。需要账号工作区同步时，点击右上角注册入口，填写邮箱和密码。

1. 注册后，在认证弹窗中输入或粘贴邮件里的六位验证码。
2. 验证码 10 分钟内有效，验证成功后自动登录。
3. 未收到邮件时，先检查垃圾箱；等待 60 秒重发倒计时结束后可重新发送，并使用最新验证码。

注册无需人机验证码。已有账号若提示邮箱未验证，也可在认证弹窗中完成验证。更多排查步骤见[账号登录与工作区同步异常](/zh/faq/common-errors#_4-账号登录与工作区同步异常)。

## 检查与验证

- [ ] 「建表 DDL」中有完整的 `CREATE TABLE` 语句，语法符合目标数据库。
- [ ] 填写了「Schema Name」时，DDL 和 DCL 中的表名带 schema 前缀。
- [ ] 点击复制按钮后显示「已复制」。
- [ ] 左侧「工作区」侧边栏的「项目」中能看到刚保存的表。

## 常见注意事项

::: warning 数据库方言匹配
若中途切换数据库类型，字段类型映射和语法规则会按新数据库重新调整。建议在开始设计前先确认目标数据库类型。
:::

- 未登录时，数据只保存在当前浏览器。点击右上角「登录 / 注册」登录后，工作区自动同步到云端，在其他设备登录同一账号即可继续编辑。
- 关闭标签页时不会弹出确认。当前编辑会自动保存为草稿，不会覆盖已保存表。
