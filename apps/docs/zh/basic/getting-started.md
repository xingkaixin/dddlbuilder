# 快速开始

## 使用对象

适合第一次使用筑表师，目标是尽快完成一张表的建表语句并复制使用。

## 解决问题

你不需要从零手写 SQL。通过页面配置，你可以在几分钟内得到可用的建表 DDL、授权 DCL、ORM 模型代码以及视图和 Routine 骨架。

## 操作步骤

1. 在表配置区域选择数据库类型，并按需填写 `Schema Name`、`表名`、`表中文名`。结果：系统明确目标数据库语法，并建立当前表对象；若填写 `Schema Name`，后续 SQL 会按 `schema.table` 生成限定表名。
2. 在“字段配置”里填写字段名、字段类型、是否为空、默认类型。结果：右侧“建表 DDL”开始实时生成可读 SQL。
3. 按需切换到“索引配置”“授权配置”“外键配置”“杂项设置”等标签补充信息。结果：DDL、DCL 与外键语句会随配置自动更新。
4. 需要快速起步时，点击顶部“表蓝图”选择常见业务模板（如用户、订单、日志），一键应用后再按需调整。结果：从空白到可用结构只需几秒钟。
5. 需要引入存量结构时，点击顶部“导入 SQL”或“导入数据”，支持 SQL、CSV、Excel、JSON Schema 多种来源。结果：系统自动解析字段与类型并回填到工作区。
6. 在右侧输出区点击“复制DDL”或“复制DCL”；也可切换到“ORM”生成 Prisma、TypeORM 等模型代码，或切换到“视图/Routine”生成对应骨架。结果：所需代码进入剪贴板，可直接发给评审或执行。
7. 需要长期保留时，点击表名右侧保存按钮并命名。结果：该表进入“已保存表”，后续可随时加载；同一工作区可打开多个标签页，每张表独立管理。

## 完成标志

- 右侧输出区出现完整 `CREATE TABLE` 语句。
- 若填写了 `Schema Name`，DDL / DCL 中已出现带 schema 的限定表名。
- 点击复制后出现“已复制”反馈。
- 打开“查看已保存表”能看到刚保存的表。
- 若使用了蓝图模板，模板字段已成功落地并可继续调整。

## 易错点

- 数据库类型选错时，生成语句会与目标库不匹配，先改数据库类型再继续编辑。
- `Schema Name` 是可选项；`表名` 只填写表本身，不要把 `schema.table` 整体写进表名输入框。
- 只配置字段、未配置授权对象时，“授权 DCL”可能为空，这是正常表现。
- 没有保存就关闭标签，虽然草稿会自动保留，但建议关键节点手动保存一份命名表。
- 如需跨设备使用或保护数据不丢失，建议点击顶部头像区域注册并登录账号。登录后可通过设置页将工作区同步到云端。
- 多标签页下，切换标签前若存在未保存变更，系统会提示保存，避免意外丢失。
