# 快速开始

本指南帮助初次使用筑表师的用户在几分钟内完成第一张数据表的结构设计，并获取高质量的建表 SQL 与相关代码。

## 适用场景

告别从零手写各数据库方言 SQL 的繁琐过程。通过直观的可视化界面，快速完成表结构建模，实时生成精准的建表 DDL、授权 DCL、ORM 模型代码以及视图和 Routine 骨架。

## 核心操作流程

### 1. 设置数据库方言与基础信息
- 在表配置区域选择目标**数据库类型**（如 MySQL、PostgreSQL、Oracle、TiDB 等）。
- 填写**表名**（如 `user_account`）与**表中文名**（如 `用户账户表`）。
- **Schema Name**（可选）：若数据库支持命名空间（如 PostgreSQL、Oracle、SQL Server），填写后系统会自动生成 `schema.table` 形式的限定表名。

::: tip 表名填写规范
`表名` 输入框仅填写纯表名即可。若需要指定命名空间，请使用专用的 `Schema Name` 输入框，不要手动在表名中输入 `schema.table`。
:::

### 2. 配置字段列表与约束
- 在“字段配置”表格中逐行录入**字段名**、**字段中文名**与**字段类型**。
- 按业务需求设置**是否为空**（`NOT NULL` / `NULL`）、**默认类型**（如常量、当前时间、UUID 等）及**默认值**。
- 右侧“建表 DDL”输出面板会实时响应并呈现标准 SQL。

### 3. 补充索引、权限与高级配置
- **索引配置**：快速添加主键、唯一索引或普通联合索引，保障查询性能。
- **授权配置**：输入目标用户或角色名称，自动生成对应的授权 `GRANT` 语句（DCL）。
- **外键与杂项**：按需设置表级存储引擎、字符集、排序规则或表空间参数。

### 4. 利用表蓝图快速起跑（可选）
如果需要设计标准业务表（如用户表、订单表、日志表等），点击顶部工具栏的**表蓝图**，挑选模板一键生成初始结构，随后按需微调即可。

### 5. 逆向导入已有结构（可选）
如果已有存量 SQL 或数据文件，点击顶部**导入 SQL**或**导入数据**（支持 CSV、Excel、JSON Schema），系统将自动解析字段、类型及索引并回填到工作区。

### 6. 复制与导出产物
- 在右侧输出区点击**复制DDL**或**复制DCL**，直接粘贴至数据库客户端或工单系统中。
- 切换至 **ORM** 标签页，可导出 Prisma、TypeORM、SQLAlchemy、GORM、JPA 等模型代码。
- 切换至 **视图/Routine** 标签页，可获取视图定义及存储过程、函数、触发器代码骨架。

### 7. 保存与多标签管理
- 点击表名右侧的**保存图标**并命名，该表将存入“已保存表”抽屉，便于随时加载与版本追踪。
- 工作区支持**多标签页**并行设计，每张表独立维护，互不冲突。

---

## 检查与验证

- [ ] 右侧输出区呈现完整、符合目标方言语法的 `CREATE TABLE` 语句。
- [ ] 若填写了 `Schema Name`，DDL/DCL 中的表名正确呈现为带命名空间的限定名称。
- [ ] 点击“复制”按钮后显示“已复制”提示。
- [ ] 打开“查看已保存表”抽屉可看到新保存的记录。

## 常见注意事项

::: warning 数据库方言匹配
若中途切换数据库类型，字段类型映射和语法规则会按新数据库重新调整。建议在开始设计前先确认目标数据库类型。
:::

- **登录与云同步**：未登录状态下数据仅保存在当前浏览器本地；建议点击右上角注册/登录账号，工作区将自动进行实时增量云端同步，多设备无缝衔接。
- **未保存提醒**：关闭包含未保存修改的标签页时，系统会弹出保存确认提示，防止误操作丢失内容。
