# 已保存表与草稿箱

本页介绍已保存表、文件夹、回收站、草稿和云同步。

## 适用场景

适用于同时维护多个项目的表、按业务模块归类表，以及在多台设备上继续编辑。

---

## 核心操作指引

### 1. 保存与打开已保存表
- 点击表配置区域的保存图标（提示为「保存当前表」）并输入名称。保存后，表出现在左侧「工作区」侧边栏的「项目」中。
- 在侧边栏的搜索框输入名称或数据库类型，可以过滤列表。
- 点击列表中的表，会在新标签页中打开它的字段、索引和 Schema Name；已经打开的表会直接切换到对应标签页。
- 在表的「更多操作」菜单中选择「重命名」。修改已打开的表后再次保存，会覆盖原记录。

### 2. 文件夹分组管理
- 点击侧边栏搜索框旁的「新建文件夹」（+），按业务领域建文件夹，如 `用户中心`、`交易结算`。
- 把表拖到文件夹中归类，或拖动文件夹调整层级。

### 3. 回收站
- 在表的菜单中点击「删除」，确认「移入回收站」后，表进入回收站。
- 点击侧边栏底部的「回收站」，在条目菜单中选择「恢复」，表回到「项目」列表。
- 选择「彻底删除」删除单个条目；点击「全部删除」清空回收站。清空后无法撤销。

### 4. 多个草稿
- 还没有保存为已保存表的设计存放在草稿箱中。
- 点击标签栏的「新建草稿」可以新建草稿。左侧「工作区」侧边栏的「草稿」分组列出所有草稿，点击即可切换。草稿不影响已保存表。

### 5. 账号登录与云同步
- **自动增量同步**：登录后，草稿、已保存表、文件夹和回收站通过 Y.Doc 自动增量同步到云端。
- **本地优先与离线可用**：在已登录设备上打开页面会优先读取本机副本。断网时可继续编辑，改动保存在本机，网络恢复后自动同步。
- **查看同步状态**：顶部栏和「设置 > 工作区同步」都会显示当前同步状态。同步失败时点击「重试同步」。同步无需手动上传或下载。
- **未登录数据迁入账号**：登录后，如果账号工作区为空，而当前浏览器还有未登录时创建的数据，系统会提示「迁移匿名工作区」。迁移不会覆盖账号中的内容。账号中已有同一项且内容不同时，本机这一项会另存为带「(Imported)」后缀的副本；内容相同则跳过。也可以选择「稍后处理」。迁移后，本机的未登录数据仍会保留。
- **退出登录**：退出前，系统会等待本机改动被云端确认保存。无法确认时会取消退出并保留本地数据，恢复同步后再重试。退出成功后，会清除本机上该账号的工作区副本。

## 校验与完成标志

- [ ] 常用表已命名保存，能在「工作区」侧边栏中搜到并打开。
- [ ] 表已按业务放入文件夹。
- [ ] 登录账号后，在其他浏览器或设备上打开能看到相同的文件夹与表列表。
- [ ] 误删的表能在「回收站」中恢复。

## 常见注意事项

- 草稿适合临时尝试。需要保留的版本，手动保存为已保存表。
- 未登录时，数据只保存在当前浏览器，清除浏览器的网站数据会导致丢失。登录后数据会同步到云端。
