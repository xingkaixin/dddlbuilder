# 已保存表与草稿箱

本指南介绍如何管理已保存表、分类文件夹、软删除回收站、多命名草稿以及跨设备云端实时同步。

## 适用场景

适用于多项目并行维护、长期沉淀团队表结构资产、按业务模块归类，以及在多台设备间无缝流转设计草案。

---

## 核心操作指引

### 1. 保存与加载已命名表
- **保存当前表**：点击表配置区域的保存图标并命名，当前表结构将作为快照存入“已保存表”。
- **查看与检索**：点击顶部或侧边的“查看已保存表”打开抽屉，支持按表名、业务中文名或数据库类型实时搜索过滤。
- **加载到工作区**：点击列表项即可将表加载至当前活动标签页，完整还原字段、索引与 Schema Name。
- **重命名与覆盖**：支持在列表菜单中直接“重命名”；修改已加载的表后再次点击保存可直接覆盖更新。

### 2. 文件夹分组管理
- **新建文件夹**：在已保存表抽屉中点击“新建文件夹”，按业务领域（如 `用户中心`、`交易结算`）建立目录。
- **拖拽归类**：直接拖拽表项至目标文件夹，或拖拽文件夹调整层级结构，保持工作区井然有序。

### 3. 软删除与回收站机制
- **安全删除**：在列表项菜单中点击“删除”，表会被移入**回收站**，防止手滑误删。
- **一键恢复**：进入回收站标签页，点击“恢复”即可将表还原至已保存表列表中。
- **彻底清空**：在回收站中执行“清空回收站”，将永久清除数据。

### 4. 侧边栏多草稿并行探索
- 未命名保存的临时表设计存放在**草稿箱**中。
- 左侧工作区侧边栏支持创建和切换**多个命名草稿**，让你在不影响已有正式表的前提下自由探索新方案。

### 5. 账号登录与云端实时同步
- **自动增量同步**：登录账号后，草稿、已保存表、文件夹层级与回收站数据会自动绑定并基于 Y.Doc 进行**实时增量云端同步**。
- **本地优先与离线可用**：在已登录设备上打开页面会优先读取本机副本。断网时可继续编辑，改动保存在本机，网络恢复后自动同步。
- **查看同步状态**：顶部栏和“设置 > 工作区同步”都会显示当前同步状态。同步失败时点击“重试同步”。同步无需手动上传或下载。
- **未登录数据迁入账号**：登录后，如果账号工作区为空，而当前浏览器还有未登录时创建的数据，系统会提示“迁移匿名工作区”。迁移不会覆盖账号中的内容：账号中已有同一项且内容不同时，本机这一项会另存为带“(Imported)”后缀的副本；内容相同则跳过。也可以选择“稍后处理”。迁移后，本机的未登录数据仍会保留。
- **退出登录**：退出前，系统会等待本机改动被云端确认保存。无法确认时会取消退出并保留本地数据，恢复同步后再重试。退出成功后，会清除本机上该账号的工作区副本。

## 校验与完成标志

- [ ] 常用表已规范命名保存，可随时从抽屉中快速检索并加载。
- [ ] 业务表已按文件夹完成清晰归类。
- [ ] 登录账号后，在不同浏览器或设备上打开能自动恢复相同的文件夹与表列表。
- [ ] 误删表可在回收站中快速找回。

## 常见注意事项

- **草稿与正式保存区分**：草稿仅用于临时演练，关键业务节点建议手动保存为已命名表。
- **未登录数据安全**：未登录状态下数据仅保存在当前浏览器本地，清理浏览器缓存会导致数据丢失，建议登录账号享受云端持久化保护。
