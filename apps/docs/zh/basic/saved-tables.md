# 已保存表与草稿箱

## 使用对象

适合需要长期维护多张表、反复切换方案、按项目整理表结构的使用者。

## 解决问题

你可以把“临时设计”和“正式保存版本”分开管理，并通过文件夹快速组织多张表。

## 操作步骤

1. 在表配置区域点击保存按钮并输入名称。结果：当前表进入“已保存表”列表，后续可重复加载；若当前表设置了 `Schema Name`，保存时会一并保留。
2. 点击 `查看已保存表` 打开侧边抽屉，按名称或数据库类型搜索。结果：你可以快速定位目标表。
3. 选择某张已保存表加载到工作区。结果：当前编辑区切换为该表，并显示加载状态；该表的 `Schema Name`、表名、字段与索引会一起恢复。
4. 需要改名或清理时，在列表执行 `重命名` 或 `删除`。结果：命名更统一，历史冗余表可及时收敛。
5. 通过 `新建文件夹`、拖拽表项、拖拽文件夹整理结构。结果：同一业务域的表可以分组管理，列表更清晰。
6. 需要回到临时工作时，切换到 `草稿箱`。结果：你可以继续未命名草稿，不影响已保存表；草稿中的 `Schema Name` 也会随工作区一起保留。
7. 登录账号后，文件夹结构会自动跟随已保存表一起同步。结果：在另一台设备登录同一账号时，已保存的表及其文件夹分组会自动恢复，无需手动重建。
8. 需要手动备份或恢复时，点击顶部头像打开 `设置`，进入 `工作区同步` 标签。结果：你可以将当前设备的完整工作区上传到云端，或从云端下载覆盖当前设备；上传/下载操作需要确认，避免误覆盖。
9. 首次登录时若浏览器中存在本地匿名数据，系统会弹出迁移提示。结果：点击开始迁移后，匿名工作区中的已保存表、草稿与文件夹会绑定到当前账号；如遇同名冲突，系统会自动另存为副本，不会覆盖云端已有内容。

## 完成标志

- 常用表已命名保存，并可从列表稳定加载。
- 文件夹层级已按业务或项目划分完成。
- 草稿箱与已保存表切换后，当前工作区状态符合预期。
- 若表使用了 schema，重新加载后 `Schema Name` 与表名组合仍与保存前一致。
- 登录账号后，文件夹与已保存表在多设备间保持一致。

## 易错点

- 已加载但未修改的表，保存按钮可能不可用，这是为了避免无效覆盖。
- 历史数据若曾把表名保存成 `schema.table`，系统加载时会自动拆分为 `Schema Name` 与纯表名；加载后建议抽查一次。
- 直接删除表不可撤销，建议先确认是否已有替代版本。
- 误把草稿当已保存表时，刷新后可能找不到命名记录，关键节点请手动保存。
- 未登录状态下，文件夹与已保存表仅保存在当前浏览器本地，换设备或清空浏览器数据后将无法恢复。如需跨设备使用，请先登录账号。
