# 索引、授权与杂项

本页介绍索引、授权语句（DCL）、杂项设置中的存储参数，以及程序单元代码骨架的配置方法。

## 适用场景

字段定义完成后，补充索引、授权和存储参数。

---

## 核心配置指引

### 1. 索引配置（Index & Key）
在「索引配置」标签页中：
- 「添加主键」：选择主键字段。一张表只能有一个主键。
- 「添加唯一索引」：用于手机号、邮箱、租户编码等需要唯一的字段。
- 「添加索引」：创建普通索引。从「字段建议」中选择一个或多个字段，选多个字段即为联合索引。
- 「索引名称」：留空时自动生成，格式为 `idx_表名_字段名`，唯一索引的前缀是 `uk_`，超过数据库标识符长度上限时截断。双击已添加的索引名可以修改。

### 2. AI 索引优化顾问
不确定常用查询该建哪些索引时：
1. 在「字段配置」工具栏打开「AI 工具」菜单，点击「AI 索引顾问」。
2. 在「典型查询 SQL」中粘贴常用查询或慢查询片段，每行一条，然后点击「分析索引」。
3. AI 根据当前字段和已有索引给出建议，分为「缺失索引」「冗余索引」「顺序优化」和「查询改写」等类别。
4. 要采纳某条建议时点击「添加索引」，索引会加入「索引配置」，DDL 随之更新。

### 3. 授权配置（DCL）
在「授权配置」标签页中：
- 输入授权对象（用户或角色，如 `app_user`、`readonly_role`），点击「添加」。
- 「生成结果」的「授权 DCL」为每个授权对象生成一条 `GRANT SELECT ON 表名 TO 授权对象;`。
- 填写了「Schema Name」时，语句中的表名带 schema 前缀。

### 4. 杂项设置（存储参数与方言选项）
在「杂项设置」标签页打开「启用杂项设置」开关后，可以设置当前数据库支持的存储参数：
- **引擎与编码**：MySQL / MariaDB 的 `ENGINE`（如 InnoDB）、`CHARACTER SET`（如 `utf8mb4`）及 `COLLATE`。
- **物理存储参数**：表空间（`TABLESPACE`）、PostgreSQL 的 `fillfactor`、Oracle 的 `PCTFREE`、`INITRANS` 等专属参数。

### 5. 程序单元代码骨架
在「生成结果」中切换到「程序单元」标签页，选择模板（存储过程、函数、自动更新时间戳触发器、审计日志触发器或自定义触发器），填写名称等参数后生成骨架代码，再到数据库中补充业务逻辑。

---

## 校验与完成标志

- [ ] 常用查询和过滤字段有索引，需要唯一的字段有唯一索引。
- [ ] 索引名称不重复，没有未选择字段的索引。
- [ ] 需要授权的用户或角色都已添加，「授权 DCL」中每个对象有一条 `GRANT` 语句。
- [ ] 启用杂项设置后，存储参数出现在 `CREATE TABLE` 语句末尾。

## 常见注意事项

::: tip 杂项设置未生效排查
杂项设置中的参数没有出现在 DDL 中时，检查面板顶部的「启用杂项设置」开关是否已打开。
:::

- **主键唯一性**：一张表只能有一个主键。已有主键时再点击「添加主键」，会提示「已存在主键」。
- **授权对象为空**：没有添加授权对象时，「授权 DCL」显示 `-- 请配置授权对象`，建表 DDL 不受影响。
