# 表与字段配置

本页介绍表配置区域和「字段配置」表格中各项的填写方法，以及字段表格工具栏中的辅助工具。

## 适用场景

适用于新建表，或在已有表上增加、修改字段和约束。

---

## 核心配置指引

### 1. 表级基础元数据
在顶部表配置区域填写：
- 「数据库类型」：选择目标数据库，如 MySQL、PostgreSQL、Oracle。
- 「表名」和「表中文名」：如 `order_item` 和 `订单明细表`。
- 「Schema Name」（可选，在「表属性」中）：目标库按 schema 区分对象时填写。例如填 `sales`，表名输出为 `sales.order_item`。不要把 schema 写进表名。

### 2. 字段录入与约束配置
在「字段配置」表格中设置每个字段：
- 「字段名」和「字段中文名」：字段的标识符和中文说明。
- 「字段类型」：填写当前数据库支持的类型，如 `BIGINT`、`VARCHAR(255)`、`DECIMAL(10,2)`、`JSON`。
- 「是否为空」：取消勾选时生成 `NOT NULL`。
- 「默认类型」和「默认值」：默认类型可选「无」「自增」「常量」「SQL 表达式」「当前时间」和「uuid」，需要具体值时填写「默认值」。
- 「更新策略」：选「当前时间」时生成 `ON UPDATE CURRENT_TIMESTAMP`。

### 3. 编辑技巧
- 点击工具栏的「添加行」，在表格末尾追加空行，旁边的加减按钮调整每次添加的行数。拖动行首的手柄可以调整字段顺序。
- 表格需要横向滚动时，打开「冻结」开关，前几列会保持可见，加减按钮调整冻结的列数。
- 点击「应用模板」插入已保存的字段模板，例如一组 `created_at`、`updated_at`、`created_by` 审计字段。在同一菜单选择「将当前行保存为模板...」，可以把当前字段存为模板。

### 4. 业务元数据与辅助工具
- **逻辑枚举（Logical Enum）**：状态码这类取值有限的字段，点击「字段类型」单元格中的「编辑枚举值」，在弹窗中填写枚举值、中文注释、英文注释和颜色标记。枚举信息随表保存。
- **容量估算**：在「数据工具」菜单中点击「估算容量」，输入预估行数。估算结果分为裸数据、索引占用和冗余开销，用于容量规划，不是实际占用的精确值。
- **结构规范检查**：点击编辑区底部的「结构规范检查」，查看命名不规范、字段类型有风险或缺少主键等问题。
- **Mock 测试数据**：在「数据工具」菜单中点击「Mock 数据」，按字段类型生成测试数据，可导出为 INSERT SQL、CSV 或 JSON。

## 校验与完成标志

- [ ] 业务需要的字段都已录入，类型和长度正确。
- [ ] 主键和非空约束已设置，需要默认值的字段已配置「默认类型」。
- [ ] 「建表 DDL」中的 SQL 完整，没有语法错误或空白占位。
- [ ] 「结构规范检查」中没有「错误」级别的问题。

## 常见注意事项与排错

::: warning 字段类型与长度变更
修改字段类型或缩短字段长度时，筑表师会弹出「数据类型变更风险」或「字段长度缩减风险」，说明可能出现的转换失败、截断或数据丢失。核实后点击「仍然修改」，或点击「取消」放弃修改。
:::

- **保留关键字**：字段名是目标数据库的保留关键字时（如 `order`、`group`），表格会提示「字段名为数据库保留关键字」，生成 DDL 时按该数据库的规则给字段名加引号。
- **外键关联前置条件**：配置外键或在 ER 图中连线时，被引用的字段必须是单字段主键或唯一索引列，两端数据类型必须兼容。
