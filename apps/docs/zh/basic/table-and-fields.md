# 表与字段配置

本指南介绍如何在表配置与字段编辑表格中录入业务属性、数据类型、约束条件及高级元数据，生成规范且可落地的 DDL。

## 适用场景

适用于在空白画布中构建全新的业务表，或在既有表结构上追加、调整字段与约束，确保输出符合目标数据库方言标准。

---

## 核心配置指引

### 1. 表级基础元数据
在顶部表配置区域完成表级标识设定：
- **数据库类型**：根据目标生产环境选择对应的数据库方言（如 MySQL、PostgreSQL、Oracle 等）。
- **表名**与**表中文名**：填写物理表名（如 `order_item`）及业务中文说明（如 `订单明细表`）。
- **Schema Name（可选）**：如果目标库采用 Schema / Namespace 隔离模式（如 `sales.order_item`），在专门的 `Schema Name` 栏填写命名空间即可，无需手动拼入表名。

### 2. 字段录入与约束配置
在“字段配置”表格中定义列属性：
- **字段名与中文名**：录入字段英文名及业务语义说明。
- **数据类型**：从类型选择器中选择方言支持的数据类型（如 `BIGINT`、`VARCHAR(255)`、`DECIMAL(10,2)`、`JSON` 等）。
- **是否为空（Nullability）**：明确标识 `NOT NULL` 或 `NULL`。
- **默认类型与默认值**：支持选择常量、空字符串、当前时间（`CURRENT_TIMESTAMP`）、UUID 或表达式默认值。
- **更新策略**：针对时间字段可配置 `ON UPDATE CURRENT_TIMESTAMP` 等自动更新行为。

### 3. 高效编辑技巧
- **批量加行与排序**：点击工具栏的“添加行”可快速批量扩充字段；支持通过左侧手柄拖拽字段上下排序。
- **冻结列与紧凑布局**：字段较多横向滚动时，可开启“冻结列”固定关键标识列；在小屏幕设备上可切换“紧凑布局”以提升可视密度。
- **字段模板复用**：点击“应用模板”可快速插入通用审计字段组（如 `created_at`、`updated_at`、`created_by` 等），也可以将当前表的字段保存为团队自定义模板。

### 4. 业务元数据与高级工具
- **逻辑枚举（Logical Enum）**：对于状态码等有限取值字段，展开行内枚举编辑器，配置枚举值、显示名与专属颜色标识。该元数据将随表保存，便于团队对齐业务语义。
- **物理存储估算**：点击“估算容量”，输入预计数据行数，系统将结合单行字节数与索引开销，精准推算磁盘占用总量。
- **Schema 规范检查（Lint）**：打开 Schema 检查面板，自动扫描潜在的命名违规、危险类型选择或缺少主键等隐患。
- **Mock 测试数据**：点击“Mock 数据”按字段类型一键生成测试样本，支持以 SQL INSERT 或 JSON/CSV 格式导出。

## 校验与完成标志

- [ ] 字段列表完整覆盖业务核心字段，类型与长度声明准确。
- [ ] 主键与非空约束明确，关键查询列已设置合理的默认值策略。
- [ ] 右侧 DDL 实时输出对应 SQL，未出现语法异常或占位空白。
- [ ] 若开启 Schema 检查，未发现高风险错误级别警告。

## 常见注意事项与排错

::: warning 字段重命名与类型变更
修改已有生产表字段类型时，请留意兼容性风险提示（如长文本截断、精度丢失）。系统会在存在数据风险时弹出告警，请核实后再应用。
:::

- **保留关键字避免**：当字段名命中目标数据库保留关键字时（如 `order`、`status`、`group` 等），系统会提示告警，生成 DDL 时将自动加上方言转义引号。
- **外键关联前置条件**：配置外键或在 ER 图中连线时，被引用的目标字段必须为单字段主键或唯一索引列，且两端数据类型必须保持兼容。
