# 表与字段配置

## 使用对象

适合已经进入编辑页面，准备把一张业务表从“空白”配置成“可生成 DDL”的使用者。

## 解决问题

你可以在一个界面里完成表级信息与字段级信息录入，快速形成可评审的表结构草案。

## 操作步骤

1. 在“表配置”中填写 `Schema Name`（可选）、`表名`、`表中文名`，并确认 `数据库类型`。结果：系统按目标数据库语法生成后续 SQL；当 `Schema Name` 不为空时，输出中的表对象会按 `schema.table` 生成。
2. 在“字段配置”逐行录入 `字段名`、`字段中文名`、`字段类型`。结果：基础字段结构实时出现在右侧 DDL。
3. 按字段规则设置 `是否为空`、`默认类型`、`默认值`、`更新策略`。结果：字段约束和默认行为写入 SQL。
4. 需要配置逻辑枚举时，在字段行内展开枚举编辑器，添加枚举项、设置颜色标识并拖拽排序。结果：该字段会附带枚举元数据，便于团队协作时统一取值规范。
5. 使用工具栏 `添加行` 批量补充字段，必要时开启 `冻结` 保持关键列可见，或切换到 `紧凑布局` 提高小屏幕下的信息密度。结果：大表编辑效率更高，横向滚动不易看错列。
6. 需要复用字段时，通过 `应用模板` 选择已有模板，或把当前字段保存为模板。结果：同类表可以快速复用统一字段集。
7. 需要预估体量时，点击 `估算容量` 调整预计行数。结果：你可以得到单行大小和总量级估算，且估算结果已纳入索引体积，更接近实际物理占用。
8. 需要检查设计规范时，打开 `Schema 检查` 面板。结果：系统按内置命名规范与类型规则扫描当前表结构，高亮潜在问题（如命名不规范、类型选择风险）。
9. 需要快速填充测试数据时，点击 `Mock 数据` 按字段类型生成样本数据并导出。结果：开发与测试阶段可快速获得符合结构的数据。
10. 需要建立表间关联时，可以切换到 `外键配置` 手工填写，也可以先保存源表和目标表，再到 `ER 关系图` 中拖动字段连接点并通过向导确认基数、可选性、级联规则和索引。结果：系统生成外键约束 DDL，并在 ER 图中展示关联关系。

## 完成标志

- 字段列表已覆盖本表核心字段，且每行字段信息完整。
- 右侧 DDL 已随字段变化实时更新，没有空白结构。
- 若使用了 `Schema Name`，右侧 SQL 中的表名已按限定名输出。
- 若使用模板，模板字段已成功落到当前表格中。
- 若配置了枚举，枚举项已保存且颜色标识符合预期。
- Schema 检查面板无高风险项，或已确认接受现有警告。

## 易错点

- 字段名重复或命中保留字时会有告警，建议先改名再继续配置。
- `Schema Name` 为空时按原来的纯表名生成；`表名` 输入框只填表名，不要把 `schema.table` 混写进去。
- 只填写字段名不设置字段类型，会导致结构信息不完整。
- 大批量粘贴后，建议逐列抽查“默认类型”和“更新策略”，避免错位。
- 修改已有字段类型时，若系统提示存在数据兼容性风险（如截断、精度丢失），请务必确认当前数据库是否已有数据，再决定是否继续。
- 配置外键时，关联字段的类型必须兼容，否则生成的外键 DDL 可能在目标库执行失败。
- 使用 ER 图关系向导时，目标字段必须是单字段主键或唯一键；一对一关系还会要求源字段具有唯一约束。
