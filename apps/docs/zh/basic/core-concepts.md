# 核心概念

深入理解筑表师的核心设计理念与机制，有助于你在日常建模、多人协作与多端流转中游刃有余。

## 概念全景速览

```mermaid
graph TD
    Workspace[工作区 Workspace] --> Tabs[多标签页 Tabs]
    Workspace --> Drafts[多命名草稿 Drafts]
    Workspace --> SavedTables[已保存表 Saved Tables]
    SavedTables --> Folders[文件夹分类 Folders]
    SavedTables --> Trash[回收站 Trash]
    
    Tabs --> Output[输出产物]
    Output --> DDL[DDL 建表 / 索引 / 分区]
    Output --> DCL[DCL 权限控制]
    Output --> ORM[ORM 模型代码]
    Output --> Routine[视图与 Routine 骨架]
    
    Workspace -. 云端实时同步 (Y.Doc) .-> Account[用户账号 & 云端存储]
    Tabs -. 生成只读分享 .-> Share[只读分享链接]
    Share -. 转为副本 .-> Workspace
```

## 核心机制详解

### 1. 工作区（Workspace）与多标签页（Tabs）
- **工作区**是你在当前会话中的顶层容器，承载了所有正在进行的表设计、草稿箱和数据状态。
- **多标签页**允许你在同一工作区内并行打开和设计多张独立的数据表，切换标签不会丢失各表的局部编辑状态。
- 关闭包含未保存变更的标签页时，系统会主动进行保存提示。

### 2. 草稿箱（Drafts）
- 未明确命名保存的临时表设计默认保存在**草稿箱**中。
- 左侧工作区侧边栏支持创建并管理**多个命名草稿**，适合快速尝试不同设计方案或做临时演进测试，不会意外覆盖已正式保存的表。

### 3. 已保存表（Saved Tables）、文件夹与回收站
- **已保存表**：点击保存后生成的命名版本快照，可在侧边抽屉随时检索与加载。
- **文件夹组织**：支持自定义文件夹层级，可通过拖拽轻松归类不同业务线或项目的表结构。
- **软删除与回收站**：删除的表会优先移入回收站并保留一段时间，可一键恢复；支持手动彻底清空。

### 4. 只读分享（Share Link）与副本转存
- 通过顶部“分享链接”生成的 URL 默认为**只读状态**，有效保护你的原始设计不被他人直接改写。
- 协作成员打开分享链接后，可点击提示条中的**保存为副本并开始编辑**，一键将表结构转入自己的工作区自由演进。

### 5. 输出产物体系（DDL / DCL / ORM / Routine）
- **DDL（Data Definition Language）**：生成包含主键、字段约束、注释、索引及分区定义的 `CREATE TABLE` 语句。
- **DCL（Data Control Language）**：生成对应的 `GRANT` 权限下发语句，避免权限与建表脱节。
- **ORM 模型代码**：将表结构精准映射为 Prisma、TypeORM、SQLAlchemy、GORM、JPA 等框架模型。
- **视图与 Routine**：输出 `CREATE VIEW` 及存储过程、函数、触发器的规范代码骨架。

### 6. 用户账号与 CRDT 实时云同步
- 登录后，工作区自动绑定到账号，底层采用基于 **CRDT（Yjs Y.Doc）** 的实时同步机制。
- 草稿、已保存表、文件夹层级与回收站状态均会在后台进行**增量自动同步**，多设备登录即可无缝续接。
- 设置页提供“立即同步”、“同步到云端”与“从云端下载”工具，并在多端并发编辑产生分歧时提供明确的冲突明细。

### 7. AI 点数中心与服务能力
- 筑表师提供全方位的 AI 辅助能力（大师建表工坊、AI 修改当前表、AI 索引顾问、DDL 架构评审、SQL 解释与智能注释）。
- AI 功能基于实际 Token 消耗计量点数。登录后可在顶部头像或设置页中的“点数中心”查看额度与明细流水。

## 关键认知清单

| 场景 / 问题 | 正确认知与应对 |
|---|---|
| **改动保存在哪里？** | 临时探索在草稿箱，确定方案后请点击保存图标生成“已保存表”。 |
| **分享链接别人能改吗？** | 不能。分享链接为只读视图，对方必须转存为副本后才能编辑。 |
| **多设备如何同步？** | 登录同一账号，系统会自动实时增量同步；亦可在设置页手动触发同步。 |
| **换电脑数据会丢吗？** | 未登录时数据仅在本地浏览器存储（清空缓存会丢失）；登录账号后数据安全存储于云端。 |
| **删除了表能找回吗？** | 能。已删除的表会存放在回收站，清空回收站前随时可一键恢复。 |
