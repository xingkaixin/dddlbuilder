# 核心概念

本页解释筑表师中的工作区、草稿箱、已保存表、只读分享、输出类型、账号同步和 AI 点数。

## 概念说明

### 1. 工作区（Workspace）与多标签页（Tabs）
- 工作区包含你的草稿、已保存表和文件夹。
- 同一工作区可以在多个标签页中分别打开不同的表，切换标签页不会丢失各自的编辑内容。
- 关闭标签页时不会弹出确认。当前编辑会自动保存为草稿，不会覆盖已保存表。

### 2. 草稿箱（Drafts）
- 还没有保存为已保存表的设计都在草稿箱中。
- 点击标签栏的「新建草稿」可以创建多个草稿，它们列在左侧「工作区」侧边栏的「草稿」分组中。草稿适合尝试不同方案，不影响已保存表。

### 3. 已保存表（Saved Tables）、文件夹与回收站
- 点击保存并命名后，表成为已保存表，出现在左侧「工作区」侧边栏的「项目」中，可以搜索和打开。
- 文件夹可以嵌套。拖动表或文件夹即可调整归类。
- 删除的表先进入「回收站」，在恢复或彻底删除之前一直保留。

### 4. 只读分享（Share Link）与副本转存
- 点击顶部「分享链接」生成的链接是只读的，打开链接的人不能修改你的设计。
- 对方点击提示条中的「保存为副本并开始编辑」，可以把表结构保存到自己的工作区再编辑。

### 5. 输出类型（DDL / DCL / ORM / 程序单元）
- **DDL（Data Definition Language）**：生成包含主键、字段约束、注释、索引及分区定义的 `CREATE TABLE` 语句。
- **DCL（Data Control Language）**：为每个授权对象生成 `GRANT SELECT` 语句。
- **ORM 模型代码**：把表结构转换为 Prisma、TypeORM、SQLAlchemy、GORM、JPA 模型。
- **视图与程序单元**：输出 `CREATE VIEW` 语句，以及存储过程、函数、触发器的代码骨架。

### 6. 用户账号与云同步
- 登录后，工作区绑定到账号，用 CRDT（Yjs Y.Doc）同步。
- 草稿、已保存表、文件夹和回收站在后台增量同步。在另一台设备登录同一账号即可继续编辑。
- 同步无需手动操作。编辑先保存到本机副本，断网时可继续编辑，网络恢复后自动同步。
- 「设置 > 工作区同步」显示当前同步状态；同步失败时可点击「重试同步」。

### 7. AI 功能与点数
- AI 功能包括「大师建表工坊」「AI 修改」「AI 索引顾问」「大师评审」「AI 代码解释器」和「AI 注释」。
- AI 功能按实际 token 消耗扣除点数。登录后点击右上角头像，选择「设置」，在「点数中心」查看余额和消费记录。

## 常见问题速查

| 问题 | 回答 |
|---|---|
| 改动保存在哪里？ | 没有保存的改动在草稿箱中。点击保存图标后，表成为已保存表。 |
| 分享链接别人能改吗？ | 不能。对方需要先点击「保存为副本并开始编辑」，编辑的是自己的副本。 |
| 多设备如何同步？ | 登录同一账号后自动同步，不需要手动上传或下载。 |
| 换电脑数据会丢吗？ | 未登录时数据只存在当前浏览器，清除浏览器数据会丢失。登录后数据同步到云端，在新电脑登录同一账号即可看到。 |
| 删除了表能找回吗？ | 能。删除的表在「回收站」中，彻底删除之前可以「恢复」。 |
