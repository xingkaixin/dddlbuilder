# 核心概念

## 使用对象

适合已经会点页面，但对“草稿、已保存表、分享副本、DDL/DCL”含义还不够清楚的使用者。

## 解决问题

理解这些概念后，你可以判断当前改动存在哪里、分享给别人后能不能编辑、该复制哪一段 SQL。

## 操作步骤

1. 先确认“工作区”概念：你当前编辑的整套配置都在同一个工作区，工作区支持多个标签页，每个标签页独立管理一张表。结果：你知道页面上每个标签内的输入都属于该标签正在设计的表，切换标签不会互相影响。
2. 理解“草稿箱”：未明确加载某张已保存表时，你处在草稿箱；草稿箱支持多个命名草稿，通过左侧工作区侧边栏管理。结果：你知道临时设计默认落在草稿箱，不会覆盖已保存表；多个草稿可同时存在并按需切换。
3. 理解“已保存表”：手动保存后形成命名快照，可反复加载；已保存表支持软删除，删除后进入回收站，可恢复或彻底清空。结果：你可以把稳定版本与临时草稿分开管理，误删后还有恢复窗口。
4. 理解“分享副本（只读）”：通过分享链接打开的页面默认不可直接编辑。结果：你知道要先点击“保存为副本并开始编辑”再修改。
5. 理解”DDL / DCL”：DDL 是建表语句，DCL 是授权语句。结果：你能按场景复制正确内容，不会混用。
6. 理解”ORM / 视图 / Routine”：ORM 是按目标框架生成的模型代码；视图是 CREATE VIEW 语句；Routine 是存储过程、函数、触发器的骨架代码。结果：你能按交付对象选择输出类型。
7. 理解”用户账号与云端同步”：登录后数据与账号绑定，可通过设置页手动上传或下载工作区快照，实现跨设备恢复。结果：你知道换设备时需要先登录，再执行同步或等待迁移提示。
8. 理解”AI 点数”：使用 AI 建表、DDL 评审、SQL 解释、AI 注释生成会按实际 token 消耗扣点。结果：你知道余额不足时需要补充点数才能继续使用 AI 功能；未登录用户需先登录才能使用 AI 功能。
9. 理解”回收站”：已保存表被删除后不会立即消失，而是进入回收站保留一段时间。结果：误删后可通过回收站恢复；批量清空回收站前请确认不再需要其中的表。

## 完成标志

- 你能说清当前是在草稿箱还是已保存表。
- 你知道多标签页下每张表是独立的，切换标签不会丢失未保存内容（但关闭标签会提示）。
- 你知道分享页不能直接改，必须先转成副本。
- 你知道结构变更看 DDL，权限发放看 DCL，业务模型看 ORM。
- 你知道登录后可通过设置页执行工作区云端同步。
- 你知道使用 AI 功能需要消耗点数且未登录时无法使用。
- 你知道删除的已保存表可在回收站恢复。

## 易错点

- 把”草稿箱自动保存”误解为”已保存表”会导致后续加载不到命名版本。
- 在分享页直接改配置不会生效，因为分享视图是只读状态。
- 只看 DDL 不看 DCL，容易漏掉授权语句下发。
- 未登录时使用 AI 功能会提示登录，登录后若点数不足也会受限。
- 未登录状态下清空浏览器数据会导致本地草稿与已保存表丢失，重要数据建议登录后同步到云端。
- 关闭带有未保存变更的标签时，若不保存直接关闭，该变更会丢失（草稿箱自动保存只针对当前活跃标签）。
