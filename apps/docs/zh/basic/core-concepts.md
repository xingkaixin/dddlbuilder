# 核心概念

## 使用对象

适合已经会点页面，但对“草稿、已保存表、分享副本、DDL/DCL”含义还不够清楚的使用者。

## 解决问题

理解这些概念后，你可以判断当前改动存在哪里、分享给别人后能不能编辑、该复制哪一段 SQL。

## 操作步骤

1. 先确认“工作区”概念：你当前编辑的整套配置都在同一个工作区。结果：你知道页面上所有输入都属于同一张正在设计的表。
2. 理解“草稿箱”：未明确加载某张已保存表时，你处在草稿箱。结果：你知道临时设计默认落在草稿箱，不会覆盖已保存表。
3. 理解“已保存表”：手动保存后形成命名快照，可反复加载。结果：你可以把稳定版本与临时草稿分开管理。
4. 理解“分享副本（只读）”：通过分享链接打开的页面默认不可直接编辑。结果：你知道要先点击“保存为副本并开始编辑”再修改。
5. 理解“DDL / DCL”：DDL 是建表语句，DCL 是授权语句。结果：你能按场景复制正确内容，不会混用。

## 完成标志

- 你能说清当前是在草稿箱还是已保存表。
- 你知道分享页不能直接改，必须先转成副本。
- 你知道结构变更看 DDL，权限发放看 DCL。

## 易错点

- 把“草稿箱自动保存”误解为“已保存表”会导致后续加载不到命名版本。
- 在分享页直接改配置不会生效，因为分享视图是只读状态。
- 只看 DDL 不看 DCL，容易漏掉授权语句下发。
