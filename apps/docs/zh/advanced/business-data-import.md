# 业务数据导入

收到订单明细、客户名单等真实 CSV / Excel 数据时，打开 **数据库工具 → 业务数据导入**。可以生成新表及 INSERT SQL，也可以对照已有表检查数据并生成 INSERT SQL。无需登录。

业务记录仅在浏览器后台线程处理，不上传、不写入工作区、不随账号同步。关闭工具或切换账号会清除本次输入和结果。结构 SQL 仍使用已有服务解析；不要把包含真实记录的 INSERT 脚本填入结构来源。

## 1. 读取数据

选择 `.csv`、`.tsv`、`.txt`、`.xlsx` 文件，或粘贴文本。CSV / 文本使用 UTF-8，按内容选择逗号、Tab 或分号分隔符，再点击 **读取数据**。Excel 先列出工作表，选择其中一张后读取；首张表为空也不影响选择其他表。

第一条记录是表头，每个名称必须非空且唯一。CSV 支持引号内换行、分隔符和双引号转义；数据行的列数必须与表头相同。全空记录跳过。错误行号保留原始文件位置，包含表头及引号内换行。

```csv
order_code,amount,created_at
00123,19.90,2026-09-01
00124,29.50,2026-09-02
```

本例中的 `00123` 会推断为文本，保留前导零；金额按精确小数处理。

| 限制 | 上限 |
| --- | --- |
| CSV / 文本 | 2 MiB |
| xlsx 压缩文件 | 5 MiB，另有解压资源检查 |
| 数据行 / 列 / 单元格总数 | 5000 / 100 / 100000 |
| 单元格文本 | 10000 字符 |
| 读取后的内容总量 | 2 Mi 字符 |

超过限制会拒绝，不会截取部分数据。Excel 不支持加密文件、合并单元格、公式及错误单元格。公式需在源文件核对结果后转为值；超出安全精度的数值需使用保留原始数字的文本单元格。已经被 Excel 舍入的数字无法恢复。日期单元格转换成 ISO；文本日期按下方明确选择的格式处理。

## 2. 确认目标和映射

### 生成新表

选择 MySQL 或 PostgreSQL，填写表名及可选的 Schema / 数据库名。工具扫描全部记录，推断整数、精确小数、布尔、日期或文本类型；混合内容使用文本。可以编辑字段名、类型、是否允许 NULL，或忽略字段。不会自动猜测主键、唯一键或业务关系。

调整格式选项后，点击 **按当前选项重新推断字段（替换编辑）** 才会重新生成字段定义。这个操作会替换已编辑的字段。切换数据库后也请重新检查目标类型。

### 对照已有表

选择一张 MySQL / PostgreSQL 普通表，来源可以是已保存表、结构快照 JSON 或结构 SQL。工具使用所选版本，不读取真实数据库。每个目标字段可选择一个源列，同名列自动匹配；未使用的源列会列出。

**不提供（使用默认值）** 表示 INSERT 中省略该字段。非空且没有默认值的字段不能省略。显式映射后的空值不会自动使用默认值。字段类型和约束来自当前所选结构，不能在映射面板中改写。

### 值的处理方式

- 默认将空单元格转换为 NULL；关闭选项后保留空字符串。字面文本 `NULL` 不自动转换。
- 默认保留首尾空格；勾选对应选项才会去除。
- 文本日期可选 ISO、DD/MM/YYYY、MM/DD/YYYY；不猜测地区格式，不接受不存在的日期。时间使用 `HH:mm:ss` 和最多 6 位小数，需符合字段精度。
- 支持常用整数、decimal/numeric、字符类型、布尔、日期/无时区时间戳、JSON，以及 PostgreSQL UUID 和 MySQL ENUM。未支持的类型阻止输出。浮点字段使用浮点语义；金额请使用 decimal。

## 3. 校验与下载

点击 **校验全部数据并生成 SQL**，检查必填、类型、整数范围、小数精度、文本长度、日期、枚举和文件内主键/唯一键重复。

有问题时不生成部分成功 SQL。页面显示前 50 个问题及源行号，可下载包含全部问题和原值的 JSON，修正源文件或映射后重新校验。修改输入、目标、映射或格式会立即清除旧结果。

通过后可以下载完整 SQL。新表模式包含 CREATE TABLE 与 INSERT，已有表模式仅包含 INSERT，每批最多 100 行。预览仅显示前 5 行和前 12000 字符，不影响下载完整性。MySQL 文本使用 UTF-8 十六进制字面量，PostgreSQL 使用 E 字符串，避免普通字符串模式改变引号和反斜线含义。SQL 不会自动执行；需要的 Schema / 数据库须已存在。

离线校验不检查数据库现有数据、外键目标、触发器和未建模的 CHECK，也不模拟数据库排序规则。省略的默认字段不参加文件内唯一检查。显式插入 PostgreSQL 自增列后需要核对序列位置。通过文件校验不代表在任意数据库版本和配置下都能执行成功。

## 复用配置

展开 **复用导入配置**，命名并保存，也可导出/导入 JSON。配置仅包含目标、列映射及格式选项，不含业务记录、错误原值和生成 SQL。保存在当前浏览器，不随账号同步；最多 50 份，导入文件最多 256 KiB。同名配置不会被静默覆盖，可换名保存或先删除旧配置。

加载前先读取本次数据；已有表配置还需先选中对应表。映射按列名恢复，不按位置套用。缺失源列、错误目标或已删除目标字段会拒绝应用；已有字段采用当前所选结构的类型并重新校验。新增加的字段需要检查映射。加载的分隔符用于后续读取文件。

字段定义清单（“字段名、字段类型、字段注释”）继续使用 [导入与解析 SQL](/zh/advanced/import-and-parse) 中的结构导入流程。
