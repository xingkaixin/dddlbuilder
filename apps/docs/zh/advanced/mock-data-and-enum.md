# Mock 数据与逻辑枚举

本指南介绍如何用筑表师生成 Mock 测试数据，以及如何为字段配置逻辑枚举。

## 适用场景

适用于开发与联调阶段填充测试数据、验证 SQL 查询，以及为状态码、类型字典等字段记录取值和含义。

---

## 操作流程

### 1. 生成并导出 Mock 数据
1. 确保表结构已完成字段与数据类型配置。
2. 在字段工具栏点击 **Mock 数据**，打开 **Mock 数据生成器**。
3. 设置生成参数：
   - 指定生成数据行数（1–100 行）。
   - 预览生成结果。生成器按字段类型生成值；字段名或注释包含 email、phone、地址等关键词时，生成对应格式的值。
4. 导出数据：
   - 在 **INSERT SQL**、**CSV**、**JSON** 标签间切换格式。
   - 点击 **复制** 或 **下载**，再导入本地测试数据库或接口调试工具。

### 2. 配置字段逻辑枚举
适用于状态码、审核状态、用户类型等离散值字段：
1. 在字段表格中找到目标字段，点击字段类型单元格中的编辑图标，打开 **编辑枚举值** 对话框。
2. 输入枚举值（如 `10`、`PAID`），按回车或点击 **添加**。在 **中文注释** 和 **英文注释** 中填写含义（如 `已支付`、`Paid`）。
3. 点击枚举项的色块选择颜色，例如绿色表示成功、红色表示拒绝、黄色表示待处理。字段类型单元格会按这些颜色显示枚举值。
4. 拖动枚举项左侧的手柄调整顺序。
5. 点击 **确定**。枚举配置随草稿与已保存表一起保存。

---

## 校验与完成标志

- [ ] 导出的 Mock 数据能导入测试数据库。
- [ ] 逻辑枚举覆盖了字段的全部业务取值，每个值都有注释和颜色。
- [ ] 重新加载已保存表后，枚举配置仍在。

## 常见注意事项

::: tip 生产敏感数据安全
Mock 数据生成器只生成随机值，不含真实业务数据。请勿在测试环境直接使用未脱敏的真实用户数据。
:::

- Mock 数据按单表字段独立生成，不检查跨表外键。插入测试库时，先插入被引用表的数据。
- 逻辑枚举不改变字段类型，也不生成数据库约束；生成 DDL 时，枚举值和注释会追加到字段注释中。需要数据库的 `ENUM` 类型时，请在字段类型中选择目标方言的 `ENUM`。
