# Mock 数据与逻辑枚举

## 使用对象

适合需要快速生成测试数据、或希望统一管理字段取值规范的使用者。

## 解决问题

Mock 数据帮助开发与测试阶段快速填充符合结构的数据；逻辑枚举则让字段取值规范可视化，减少团队协作时的理解偏差。

## 前置条件

- 当前表已完成字段配置。
- Mock 数据生成需明确目标行数与导出格式。

## 操作步骤

### Mock 数据生成

1. 在表配置区域或字段配置工具栏点击 `Mock 数据`。结果：打开 Mock 数据生成对话框。
2. 设置目标行数（如 100、1000）。结果：系统按字段类型生成对应格式的随机数据。
3. 检查生成预览，确认字符串长度、数值范围、日期格式是否符合预期。结果：若偏差较大，可回到字段配置调整默认值或类型后再重新生成。
4. 选择导出格式（如 SQL INSERT、CSV、JSON）。结果：数据批量导出，可直接导入测试数据库或传给测试同事。

### 逻辑枚举配置

1. 在字段配置表格中找到目标字段，展开 `枚举` 编辑器。结果：出现枚举项管理面板。
2. 点击 `添加枚举项`，输入枚举值与显示名。结果：枚举列表增加一项。
3. 为枚举项选择颜色标识。结果：不同枚举值在界面上以不同颜色区分，便于快速识别。
4. 拖拽枚举项调整顺序。结果：顺序会持久化到草稿与已保存表。
5. 填写字段中文名时，可备注该字段的枚举规范。结果：团队协作时更容易理解取值含义。

## 完成标志

- Mock 数据已导出且格式正确，可直接用于测试。
- 枚举项已覆盖业务所有有效取值，颜色标识直观。
- 枚举元数据已随表保存，重新加载后依然有效。

## 易错点

- Mock 数据是随机生成的，不代表真实业务分布；涉及敏感字段（如手机号、身份证）时，建议用脱敏规则二次处理。
- 枚举值修改后，已生成的 Mock 数据不会自动更新，需重新生成。
- 并非所有数据库类型都原生支持枚举类型；系统会在 DDL 中以注释或约束形式表达枚举规范，具体生效方式取决于目标数据库。
- 枚举颜色仅在界面展示，不会写入 DDL。
