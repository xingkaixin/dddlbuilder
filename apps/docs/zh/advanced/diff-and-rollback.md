# 变更对比与回滚

本指南介绍如何用筑表师对比表结构变更、生成 ALTER 脚本和回滚脚本，以及查看和回放版本历史。

## 适用场景

适用于修改已有业务表的字段、类型或索引时，在上线前准备好发布脚本和回滚脚本。

---

## 操作流程

### 1. 查看结构差异
1. 在「工作区」中加载一张已保存表。
2. 在编辑器中增删字段、修改类型或调整索引。
3. 在表配置区域点击 **更多**，选择 **查看表结构变更**。
4. 在 **表结构变更对比** 弹窗中查看表配置、字段（新增、删除、重命名和属性修改）及索引的变更。

### 2. 复制 ALTER 脚本与回滚脚本
- 在 **变更脚本** 区域点击 **复制**，得到发布用的 ALTER 语句。
- 展开 **回滚脚本** 区域，点击 **复制回滚**。回滚脚本是反向的 ALTER 语句，用于撤销上面的变更。

### 3. 版本历史与回滚
- 加载已保存表后，在表配置区域点击 **历史版本**。
- 查看该表每次保存的版本、保存时间与变更摘要。
- 选中一个历史版本，点击 **回滚到该版本**，编辑器内容恢复为该版本。

### 4. 回放 Schema 变更
- 在 **版本历史** 弹窗中点击 **播放回放**。
- 播放器按版本顺序逐帧展示表结构从初始版本到最新版本的变化。

---

## 校验与完成标志

- [ ] 变更对比包含本次的全部修改，改名的字段显示为重命名。
- [ ] ALTER 脚本的语法与目标数据库版本匹配。
- [ ] 已保留对应的回滚脚本，作为上线方案的故障预案。
- [ ] 能在版本历史中找到历史版本并回滚。

## 常见注意事项

::: warning 线上数据兼容性风险
ALTER 与回滚脚本只处理结构定义。若涉及字段缩短、类型强转或添加非空且无默认值的列，执行前请评估线上存量数据的迁移与兼容性。
:::

- **查看表结构变更** 只在加载已保存表并产生实际改动后出现。从未保存过的草稿没有基线版本，不会出现这个入口。
- 每次覆盖保存表都会追加一条历史版本。
