# 高级技巧

## 使用对象

适合已经能完成常规建表，准备处理“导入存量 SQL、AI 协作、结构变更控制、分区分片策略、外键与 ER 图、ORM 生成”等复杂场景的使用者。

## 解决问题

高级技巧帮助你把“能生成 SQL”推进到“可稳定复用、可协作评审、可控制变更风险、可对接业务项目”。

## 前置条件

- 你已经完成基础指南中的常规建表流程。
- 你知道如何在页面中查看 DDL、DCL、ORM 与视图/Routine 输出。
