# 导入 SQL 建表语句并编辑表结构

打开[筑表师的建模工作区](https://ddl.xingkaixin.me/)，再按下面的步骤导入。导入多张关联表后，可通过[外键配置与 ER 图](/zh/advanced/foreign-key-and-er)检查关系，再用[ORM 模型生成](/zh/advanced/orm-generation)导出代码。

本指南介绍如何把现有的 SQL 脚本或字段定义文件（CSV、Excel、JSON Schema）导入为可编辑的表结构。

## 适用场景

适用于重构存量系统、迁移老项目数据库，或从第三方接口定义、Excel 数据字典生成表结构。

---

## 操作流程

### 1. 导入单表或多表 SQL
1. 点击顶栏的 **导入结构**。需要一次保存多张表时，将 **导入方式** 设为 **保存为已保存表**。
2. **来源类型** 选择 SQL，选择 **源数据库**，粘贴 SQL 脚本（支持单条或多条 `CREATE TABLE`、`CREATE INDEX`、`ALTER TABLE`、`GRANT` 语句）。
3. 点击 **下一步**，校验语法并解析表结构。
4. 核对和调整解析结果：
   - 导入到工作区时，在预览中检查解析出的字段、类型、主键、索引及授权对象，可以修改字段名、类型和可空性，或上移、下移、删除字段。核对后点击 **下一步**。
   - 选择 **保存为已保存表** 时，没有字段预览。勾选要导入的表，点击 **下一步**，再选择 **目标文件夹** 和 **同名冲突策略**：**跳过已存在**、**覆盖已有** 或 **自动重命名**。
5. 点击 **确认导入**。若 SQL 带 Schema 前缀（如 `CREATE TABLE sales.orders`），`sales` 填入 `Schema Name`，`orders` 填入 `表名`。

### 2. 导入字段定义文件（CSV / Excel / JSON Schema）

真实订单、客户名单等业务记录请使用 [业务数据导入](/zh/advanced/business-data-import)。本页的 CSV / Excel 导入处理字段定义清单。

1. 点击顶栏的 **导入结构**，在 **来源类型** 中选择：
   - **CSV / TSV**：首行为表头（字段名、字段类型、字段注释），之后每行描述一个字段。
   - **Excel**（.xlsx / .xls）：每个工作表导入为一张表，工作表名作为表名。第 1 行为表头（字段名、字段类型、字段注释），之后每行一个字段。
   - **JSON Schema / OpenAPI**：读取 `properties` 中的字段及其类型、格式与描述。
2. 上传文件，点击 **下一步**，在预览中核对字段和类型，按需修改。
3. 点击 **确认导入**，字段写入当前工作区。

---

## 支持语句与文件规范

| 格式 / 来源 | 支持语法与对象规范 | 解析行为说明 |
|---|---|---|
| **SQL 脚本** | `CREATE TABLE`、`CREATE INDEX`、`ALTER TABLE`、`GRANT` | 提取列约束、默认值、注释、联合索引及授权 |
| **CSV 文件** | UTF-8 编码，英文逗号分隔，首行为表头 | 读取字段名、显式 SQL 类型与注释 |
| **Excel 文件** | 支持 `.xlsx`、`.xls` 格式 | 读取各工作表中的字段定义清单 |
| **JSON Schema** | JSON Schema、Swagger 或 OpenAPI 文档 | 提取 `properties`，按 `type` 和 `format` 映射字段类型，`object` 和 `array` 映射为 `json` |

---

## 校验与完成标志

- [ ] 工作区显示了解析出的表名、字段、约束和索引。
- [ ] 源 SQL 带 Schema 前缀时，`Schema Name` 与 `表名` 已分别填入。
- [ ] 生成结果中的 DDL 与 DCL 符合目标数据库的语法。

## 常见注意事项与排错

::: tip 方言不匹配排查
导入时提示语法错误，先检查导入弹窗中的 **源数据库** 是否与 SQL 的实际语法一致，例如把 Oracle 语法选成了 MySQL。
:::

- 单次导入的 SQL 最多 50,000 个字符。超出时按业务模块分批导入。
- CSV 文件需保存为 UTF-8 编码。Excel 文件需先解除密码保护再上传。
- JSON Schema 中嵌套的 `object` 和 `array` 属性会导入为一个 `json` 字段。需要拆成多张表时，先在 JSON Schema 中拆出实体再导入。
