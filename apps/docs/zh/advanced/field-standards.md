# 字段标准库与业务词典

字段标准用来统一业务概念及其字段定义。例如，将“订单金额”定义为 `amount decimal(18,2)`，记录单位“元”和业务含义，再检查各表是否遵循同一标准。

## 创建标准

1. 打开一张表，在字段工具栏点击 **字段标准库**。
2. 点击 **新建标准**，或选择“当前表字段”后点击 **从此字段创建标准**。
3. 填写业务名称、业务定义和业务单位。
4. 编辑标准字段的名称、类型、说明、可空性、默认值、更新策略和枚举定义。
5. 点击 **保存标准**。每个标准定义一个字段；业务单位和业务定义是说明信息，不会自动转换数据或写入 DDL。

## 引用与更新

选择一个标准和当前表字段，面板会并排显示当前值与标准值，并高亮差异。

- **仅关联，不修改字段**：记录引用，保留当前字段内容，供后续检查。
- **应用标准并关联**：使用面板中的标准属性覆盖所选字段，保留字段身份。
- **新增标准字段**：在当前表中添加引用该标准的字段。同名字段已存在时不能添加。
- **解除关联**：保留字段内容，移除标准引用。

编辑标准后，已有字段不会自动更新。“当前表的标准引用”会显示偏差数量；点击 **查看差异**，核对后再决定是否应用。字段改动仍需按正常流程保存表，数据库迁移也需要另外执行。

## 检查已保存表

点击 **检查已保存表**，查看当前工作区已保存表中的引用和偏差。同名但未关联的字段也会列出。检查不包含未保存草稿；结果是检查时点的快照，修改表后需重新检查。需要修正时，打开对应表，在标准库中核对并应用。

## 保存与分享

标准库保存在当前浏览器，独立于账号工作区。可通过 JSON 导出备份或分享，导入时会预览标准名称与同 ID 覆盖数量，确认后合并。导入文件上限为 2 MiB、1000 个标准。

字段引用会随表保存、分享和账号同步。其他设备或协作者需要导入同一份标准库，才能解析相同的标准 ID。删除标准不会删除表字段；缺失的引用会保留并提示“标准缺失”，重新导入同 ID 标准即可恢复。
