# 表蓝图模板

整表蓝本保存一张表的字段、索引、数据库类型和表级配置。应用蓝本时，筑表师在新的草稿标签页中打开这份结构。蓝本保存在当前浏览器。

## 适用场景

适用于需要反复创建结构相近的表（如多张订单表或日志表）。先把其中一张保存为蓝本，之后从蓝本开始，不必逐行录入字段和索引。

---

## 蓝本包含的内容

| 内容 | 应用蓝本后 |
|---|---|
| 字段、索引 | 复制到新草稿 |
| 数据库类型 | 新草稿使用蓝本的数据库类型 |
| 表级配置（如 MySQL 分区、Citus 分片） | 复制到新草稿 |
| 表名、表注释、Schema Name、授权对象 | 不存入蓝本，新草稿沿用当前标签页的设置 |
| 外键 | 不存入蓝本，应用后需重新配置 |

---

## 核心操作流程

1. 在字段表格上方的工具栏点击 **整表蓝本**。
2. 保存蓝本：
   - 编辑好一张表后，选择 **将当前表保存为蓝本...**。
   - 填写蓝本名称和可选的描述，点击 **保存蓝本**。
3. 挑选与预览蓝本：
   - 在列表中按蓝本名称或字段搜索。
   - 点击蓝本打开预览，查看数据库类型、字段列表和索引列表。
4. 应用蓝本：
   - 在预览中点击 **应用蓝本**。
   - 结构在新的草稿标签页中打开，原标签页内容不变。
5. 按业务调整：
   - 增删字段、调整 VARCHAR 长度或修改默认值。
   - 点击保存图标，将其命名存入“已保存表”。
6. 需要重命名、复制或删除蓝本时，选择 **管理蓝本...**。

---

## 校验与完成标志

- [ ] 蓝本结构已在新的草稿标签页中打开。
- [ ] 字段长度、精度与默认值已根据具体业务调整完毕。
- [ ] 生成结果中的 DDL 符合目标方言。

## 常见注意事项

::: tip 应用后按业务调整
蓝本复制的是保存时的结构。用于新表前，按业务并发量、合规要求（如手机号脱敏或加密字段）与方言特性调整。
:::

- 蓝本不保存外键。应用后，在“外键配置”或“ER 关系图”中为新表建立关联。
- 蓝本带有保存时的字段注释。用于其他业务时，按该业务的术语修改注释。
