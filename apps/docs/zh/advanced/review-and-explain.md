# 评审与解释 SQL

本指南介绍如何使用筑表师的**大师评审**功能进行专家级 DDL 质量审计，并通过**SQL 解释**功能快速解析复杂语句片段的语义与业务影响。

## 适用场景

适用于在表结构提交技术委员会评审、录入 DBA 工单上线前进行自我审查，或在阅读遗留复杂 SQL 时快速理清各子句与方言特性的作用。

---

## 核心操作指引

### 1. 大师评审（Architect-Level Quality Audit）
1. 确认当前表已配置好字段并在右侧生成有效 DDL。
2. 在右侧输出区域点击**大师评审**按钮。
3. **查看多维度综合评分与诊断报告**：
   - 系统从**命名规范**、**数据类型选型**、**索引合理性**、**完整性约束**、**扩展性**与**潜在性能风险**等维度进行深度扫描并给出综合评分（1–10 分）。
   - 输出明确的问题级别（高风险、优化建议、良好实践）与修改理由。
4. **一键采纳与应用**：对于结构性的优化建议（如建议添加联合索引、调整字段长度），可直接点击建议卡片上的**应用**按钮，系统将自动回填修改至字段或索引配置中。
5. **追溯评审历史**：点击评审面板顶部的历史图标，可查看当前表以往的各轮评审记录与评分变迁。

### 2. SQL 片段解释（Explain Selected SQL）
1. 在右侧输出面板的 SQL 代码区中，使用鼠标高亮选中任意感兴趣的语句或子句片段（如特殊的索引选项、分区定义或存储参数）。
2. 代码旁会自动浮现**解释选中**工具气泡。
3. 点击“解释选中”，AI 将即时解析该语法片段在目标数据库中的**执行语义**、**方言特性**以及**在业务场景中的作用**，帮助团队消除沟通壁垒。

---

## 校验与完成标志

- [ ] 当前表已通过大师评审，无未确认的高风险阻断项。
- [ ] 采纳的架构优化建议已成功同步至表配置中，右侧 DDL 完成更新。
- [ ] 复杂 SQL 片段均具备清晰的解释说明，便于评审答辩。

## 常见注意事项

::: tip 建议应用后的二次复核
大师评审提供的是基于最佳实践的通用架构建议。对于涉及特殊业务规则的改动（如特定的反范式冗余字段），请结合实际业务需求决定是否采纳。
:::

- **有效 DDL 前置**：必须在表名和字段完整、右侧生成有效 DDL 后方可发起评审。
- **高亮选区精准度**：使用“解释选中”时，请确保完整选中目标语句语法块，以获取最精准的语义解析。
