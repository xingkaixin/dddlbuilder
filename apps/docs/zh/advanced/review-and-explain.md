# 评审与解释 SQL

本页介绍如何用**大师评审**检查当前表的 DDL，以及如何用**解释选中**让 AI 解释一段 SQL。

## 适用场景

表结构交给 DBA 审核或上线前，先自查一遍；阅读不熟悉的 SQL 时，逐段查看各子句的作用。

---

## 核心操作指引

### 1. 大师评审
1. 确认当前表已配置好字段，已生成 DDL。
2. 在生成结果的“建表 DDL”标签页中点击**大师评审**。
3. 查看评分与建议：
   - AI 从命名规范、数据类型选择、索引设计、完整性约束、可扩展性和性能六个方面评审，给出 1–10 分的评分和简短总结。
   - 建议逐条列出。性能问题会标为“严重”或“警告”。
4. 新增、修改、删除字段以及新增、删除索引的建议带有**应用**按钮，点击后改动写入字段或索引配置。性能提示和一般建议只供参考，不能自动应用。
5. 点击**大师评审**旁的历史图标，打开“评审历史”，查看以往评审的分数和建议。

### 2. 解释选中的 SQL
1. 在生成结果的 SQL 代码区中，用鼠标选中一段语句或子句，如索引选项、分区定义或存储参数。
2. 选区旁会出现**解释选中**按钮。未登录时按钮显示为“登录后解释”。
3. 点击**解释选中**，AI 会说明这段 SQL 的作用和要点。

---

## 校验与完成标志

- [ ] 当前表已完成大师评审，标为“严重”的问题都已处理或确认。
- [ ] 已应用的建议出现在表配置中，DDL 已更新。
- [ ] 需要在评审中说明的复杂 SQL 片段都已有解释。

## 常见注意事项

::: tip 应用建议前核对业务规则
大师评审给出的是通用的数据库设计建议。涉及特殊业务规则的改动（如有意保留的反范式冗余字段），请按实际需求决定是否采纳。
:::

- 没有生成 DDL 时，**大师评审**按钮不可用。数据库类型为 SQLite / D1 时也不可用。
- 使用**解释选中**时，选中完整的语句或子句。
