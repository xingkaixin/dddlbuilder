# PostgreSQL CREATE TABLE & 索引生成器

筑表师（DDLBuilder）提供符合 PostgreSQL 原生语法的在线建表与索引生成能力：自动输出 `GENERATED BY DEFAULT AS IDENTITY`、Schema 限定表名、独立 `COMMENT ON` 语句、`ALTER TABLE ... ADD CONSTRAINT` 主键、`CREATE INDEX`（含 `ASC`/`DESC`）以及 `WITH (fillfactor = ...)` 表级存储参数。

## 真实 DDL 输出示例：带索引与存储参数的支付订单表

点击本页示例按钮即可在筑表师新草稿中载入以下 PostgreSQL 支付订单表，包含 `app` Schema、`JSONB` / `TIMESTAMPTZ` 字段、唯一索引与复合排序索引：

```sql
CREATE TABLE app.payment_orders (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY NOT NULL,
  order_no VARCHAR(64) NOT NULL,
  user_id BIGINT NOT NULL,
  amount_cents BIGINT NOT NULL DEFAULT 0,
  currency CHAR(3) NOT NULL DEFAULT 'CNY',
  metadata JSONB,
  paid_at TIMESTAMP WITH TIME ZONE,
  created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP
) WITH (fillfactor = 90);
COMMENT ON TABLE app.payment_orders IS '支付订单表';
COMMENT ON COLUMN app.payment_orders.id IS '主键ID';
COMMENT ON COLUMN app.payment_orders.order_no IS '外部订单号';
COMMENT ON COLUMN app.payment_orders.user_id IS '用户ID';
COMMENT ON COLUMN app.payment_orders.amount_cents IS '金额（分）';
COMMENT ON COLUMN app.payment_orders.currency IS '币种';
COMMENT ON COLUMN app.payment_orders.metadata IS '扩展元数据';
COMMENT ON COLUMN app.payment_orders.paid_at IS '支付时间';
COMMENT ON COLUMN app.payment_orders.created_at IS '创建时间';

ALTER TABLE app.payment_orders ADD CONSTRAINT pk_payment_orders PRIMARY KEY (id);
CREATE UNIQUE INDEX uk_payment_orders_order_no ON app.payment_orders (order_no ASC);
CREATE INDEX idx_payment_orders_user_created ON app.payment_orders (user_id ASC, created_at DESC);
```

## 核心能力

- **标准 PostgreSQL 语法**：按 PostgreSQL 真实语法输出独立 `COMMENT ON`、`ADD CONSTRAINT` 主键与 `CREATE [UNIQUE] INDEX`，不用通用 SQL 近似。
- **Schema 命名空间**：填写 Schema 名称后，建表语句、注释、约束、索引以及 Prisma `@@schema(...)` 同步带入命名空间。
- **表级存储参数**：支持在 **高级设置 → 表级选项** 配置 `tablespace` 和 `fillfactor`。
- **Citus 分布式扩展**：切换为 **PostgreSQL (Citus)** 可配置副本表或分片字段，生成 `SELECT create_distributed_table(...)`。
- **结构对比与跨方言评估**：支持对比两份 PostgreSQL 结构并输出迁移 SQL；也可对 MySQL 与 PostgreSQL 做迁移兼容性评估。

## 操作步骤

1. 点击本页按钮打开预置的 `app.payment_orders` PostgreSQL 示例。
2. 按需修改 Schema 名称、字段类型（如 `JSONB`、`UUID`、`TIMESTAMPTZ`）与默认值。
3. 在 **索引配置** 调整唯一索引与查询复合索引的字段排序方向。
4. 在 **高级设置 → 表级选项** 调整 `fillfactor` 或表空间。
5. 复制完整 DDL，或切换到 **ORM 模型** 导出 Prisma / TypeORM / SQLAlchemy / GORM / JPA 模型。

## 常见问题

### PostgreSQL 的表注释和字段注释是如何生成的？

PostgreSQL 不支持在 `CREATE TABLE` 列定义内写内联 `COMMENT`。筑表师会自动在建表语句之后生成标准的 `COMMENT ON TABLE` 与 `COMMENT ON COLUMN` 语句。

### 支持 PostgreSQL 的 IDENTITY 主键和 JSONB / TIMESTAMPTZ 吗？

支持。勾选自增后会按 PostgreSQL 标准生成 `GENERATED BY DEFAULT AS IDENTITY`，同时支持 `JSONB`、`TIMESTAMPTZ`、`CHAR`、`VARCHAR` 等常见类型。

### 支持 PostgreSQL Citus 分布式表吗？

支持。将数据库类型切换为 **PostgreSQL (Citus)** 后，可在高级设置中配置副本表或分布式分片键，并自动追加 `create_distributed_table` 语句。
