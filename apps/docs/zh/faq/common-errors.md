# 报错与失败处理

本页列出使用筑表师时常见的报错和异常，以及对应的排查步骤。

---

## 1. 分享链接不可用或提示已过期

### 现象描述
打开他人发送的分享链接后，页面提示“分享链接不存在或已过期，已返回首页”，并回到首页。

### 排查与解决步骤
1. 检查链接是否被聊天工具（如微信、企业微信、钉钉）截断或拼接了多余字符。把完整 URL 复制到浏览器地址栏中打开。
2. 分享链接的有效期为 7 天。过期后请联系分享人重新生成。
3. 分享人打开原表，点击顶部的“分享链接”，把新 URL 发给对方。

---

## 2. SQL 逆向导入失败或解析不完整

### 现象描述
- 校验阶段提示“SQL 解析失败”或语法错误。
- 导入后部分字段、索引或授权对象缺失。

### 排查与解决步骤
1. 确认导入弹窗中的“源数据库”与 SQL 的实际方言一致，例如导入 Oracle 脚本时选择 Oracle。
2. 先只导入 `CREATE TABLE` 语句，确认表结构能被识别。
3. 脚本较长或包含触发器、存储过程时，分段导入，找出出错的语句。
4. 删除数据库客户端使用的环境指令，如 `USE database;`、`SET NAMES utf8mb4;`。

---

## 3. AI 请求失败（建表、修改、评审或解释）

### 现象描述
- “大师建表工坊”提示生成中断或请求失败。
- “大师评审”或“解释选中”无响应或报错。

### 排查与解决步骤
1. 网络短暂波动时，刷新页面后重试一次。
2. 不要在一次提示词中要求生成几十张表。先生成单表的核心字段，再补充索引，最后调整约束，分几轮对话完成。
3. 点击右上角头像，进入“设置 > 点数中心”查看点数余额。余额为 0 时无法使用 AI 功能，界面会提示“当前额度不足，暂时无法使用 AI 功能”。

---

## 4. 账号登录与工作区同步异常

### 现象描述
- 登录时提示“邮箱尚未验证”或“操作过于频繁”。
- 工作区同步状态显示“同步失败”“网络异常”或“同步服务不可用”。
- 退出登录时提示“还有内容未确认同步到云端，已取消退出”。

### 排查与解决步骤
1. 提示邮箱未验证时，输入邮件中的六位验证码，验证成功后会自动登录。验证码 10 分钟内有效。未收到时请检查垃圾箱，或在倒计时结束后重新发送。重发后请使用最新验证码。
2. 提示操作频繁时，说明同一 IP 在 15 分钟内登录超过 10 次，触发了限流。最多等待 15 分钟后重试。
3. 检查网络后，点击顶部同步状态旁的刷新图标，或在“设置 > 工作区同步”中点击“重试同步”。
4. 退出登录被取消是为了避免丢失未同步的改动，本地数据已保留。先按上一步恢复同步，状态变为“云端已同步”后再退出。

---

## 5. 剪贴板复制失败

### 现象描述
点击“复制DDL”或“复制DCL”按钮后提示“复制失败，请重试”。

### 排查与解决步骤
1. 检查浏览器地址栏右侧或站点权限设置，确认没有禁止当前站点写入剪贴板。
2. 在远程桌面或受限的内网浏览器中，直接用鼠标选中生成结果中的 SQL 代码，按 `Ctrl+C` / `Cmd+C` 复制。
