# 报错与失败处理

本页面汇总了在使用筑表师过程中可能遇到的常见报错、异常现象及排查解决步骤。

---

## 1. 分享链接不可用或提示已过期

### 现象描述
打开他人发送的分享链接后，页面提示“分享链接不存在或已过期”，并自动返回首页。

### 排查与解决步骤
1. **核对链接完整性**：检查链接是否被聊天工具（如微信、企业微信、钉钉）自动截断或拼接了多余字符。建议将完整 URL 复制至浏览器地址栏直接打开。
2. **确认时效性**：分享链接默认具备有效时效（通常为 7 天）。若已超时，请联系发起人重新点击“分享链接”生成新链接。
3. **重新生成**：作为分享方，打开原表重新点击顶部“分享链接”，获取新 URL 发送给对方。

---

## 2. SQL 逆向导入失败或解析不完整

### 现象描述
- 校验阶段提示“SQL 解析失败”或语法错误。
- 导入后部分字段、索引或授权对象缺失。

### 排查与解决步骤
1. **核对源数据库方言**：确认导入弹窗中的“源数据库”与待解析 SQL 的实际方言一致（如避免用 MySQL 解析器导入 Oracle 专属语法）。
2. **聚焦核心建表语句**：优先提取最核心的 `CREATE TABLE` 语句导入，确保基础实体结构被成功识别。
3. **分批排查复杂子句**：若脚本过长或包含复杂触发器、存储过程，建议分段追加导入以精确定位报错语法块。
4. **清理特殊非标语句**：移除数据库客户端专属的非标指令（如 `USE database;`、`SET NAMES utf8mb4;` 等环境指令）。

## 3. AI 请求失败（建表、修改、评审或解释）

### 现象描述
- “大师建表工坊”提示生成中断或请求失败。
- “大师评审”或“解释选中”无响应或报错。

### 排查与解决步骤
1. **短时网络波动**：刷新页面后重试一次相同操作。
2. **拆分长提示词**：避免在单次提示词中一次性要求生成数十张表；建议按“单表核心字段 → 补充索引 → 调整约束”进行小步对话迭代。
3. **检查 AI 点数余额**：点击右上角头像进入“设置 > 点数中心”，确认账号点数是否充足。余额不足时需补充点数后方可继续使用。

---

## 4. 账号登录与工作区同步异常

### 现象描述
- 登录时提示“邮箱尚未验证”或“操作过于频繁”。
- 工作区同步提示“同步失败”或出现冲突警告。

### 排查与解决步骤
1. **邮箱激活验证**：若提示未验证，请前往注册邮箱查收激活邮件（若未收到请检查垃圾箱），点击验证链接完成激活。
2. **防暴力限流保护**：若提示操作频繁，通常为短时间内连续尝试触发了安全防护，请静待 1–2 分钟后重试。
3. **刷新恢复同步状态**：进入“设置 > 工作区同步”，点击“立即同步”；若多端产生冲突，可展开冲突明细进行确认。

---

## 5. 剪贴板复制失败

### 现象描述
点击“复制DDL”或“复制DCL”按钮后提示“复制失败，请重试”。

### 排查与解决步骤
1. **浏览器剪贴板权限**：检查浏览器地址栏右侧或权限设置，确认未禁用当前站点的剪贴板写入权限。
2. **快捷键手动兜底**：在受限环境（如远程桌面或安全内网浏览器）中，直接用鼠标选中右侧 SQL 代码区，使用系统快捷键（`Ctrl+C` / `Cmd+C`）进行手动复制。
