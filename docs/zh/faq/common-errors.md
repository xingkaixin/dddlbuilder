# 报错与失败处理

## 分享链接不可用

### 现象

打开分享链接后提示“分享链接不存在或已过期”，并返回首页。

### 快速判断

- 该链接是否超过 7 天。
- 链接是否被截断或包含多余字符。

### 处理步骤

1. 先完整复制并重新打开原链接。结果：可排除“链接被聊天工具截断”的问题。
2. 若仍失败，回到当前表重新点击“分享链接”。结果：系统会生成可用链接并复制到剪贴板。
3. 将新链接发给协作方并让对方重试。结果：多数过期或失效问题会被解决。

### 仍未解决时

请先在同一网络环境下自行打开新链接；若你本机也无法打开，再联系产品支持并附上出现时间与页面提示。

## SQL 导入失败或结果异常

### 现象

- 校验阶段提示“SQL 解析失败”。
- 导入后字段、索引或授权对象不完整。

### 快速判断

- SQL 是否为空或过长。
- “源数据库”是否与 SQL 方言一致。

### 处理步骤

1. 在导入弹窗确认“源数据库”选择正确。结果：系统按目标方言重新解析。
2. 优先导入最核心的 `CREATE TABLE` 语句。结果：先确保主结构可被识别。
3. 再逐段追加 `CREATE INDEX`、`ALTER TABLE`、`GRANT`。结果：你可以快速定位是哪段语句触发异常。
4. 如果 SQL 很长，先拆分后分批导入。结果：可避免超长文本导致的校验失败。

### 仍未解决时

保留最小可复现 SQL 片段并记录所选数据库类型，再提交给产品支持排查。

## AI 请求失败（生成、评审、解释）

### 现象

- 大师建表工坊生成失败。
- 大师评审失败。
- 解释选中失败。

### 快速判断

- 是否是短时网络抖动。
- 是否在同一时间高频连续触发 AI 请求。

### 处理步骤

1. 刷新页面后重试一次同样操作。结果：可排除临时会话异常。
2. 将一次长请求拆成多次短请求。结果：成功率通常更高。
3. 避开高峰时段再试。结果：可降低服务拥堵导致的失败概率。

### 仍未解决时

记录失败操作名称（生成/评审/解释）与触发时间，再联系产品支持。

## 复制失败

### 现象

点击“复制DDL”或“复制DCL”后提示“复制失败，请重试”。

### 快速判断

- 当前浏览器是否禁止剪贴板权限。
- 是否在受限环境（远程桌面、受管浏览器策略）中使用。

### 处理步骤

1. 先重试一次复制按钮。结果：可排除偶发失败。
2. 若仍失败，手动选中右侧 SQL 文本后使用系统复制快捷键。结果：可继续完成交付，不阻塞流程。
3. 必要时切换到常用浏览器再复制。结果：可规避当前浏览器策略限制。

### 仍未解决时

确认你的工作环境是否限制剪贴板访问，必要时联系本地 IT 管理员协助。
