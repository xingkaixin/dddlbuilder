# 已保存表与草稿箱

## 使用对象

适合需要长期维护多张表、反复切换方案、按项目整理表结构的使用者。

## 解决问题

你可以把“临时设计”和“正式保存版本”分开管理，并通过文件夹快速组织多张表。

## 操作步骤

1. 在表配置区域点击保存按钮并输入名称。结果：当前表进入“已保存表”列表，后续可重复加载。
2. 点击 `查看已保存表` 打开侧边抽屉，按名称或数据库类型搜索。结果：你可以快速定位目标表。
3. 选择某张已保存表加载到工作区。结果：当前编辑区切换为该表，并显示加载状态。
4. 需要改名或清理时，在列表执行 `重命名` 或 `删除`。结果：命名更统一，历史冗余表可及时收敛。
5. 通过 `新建文件夹`、拖拽表项、拖拽文件夹整理结构。结果：同一业务域的表可以分组管理，列表更清晰。
6. 需要回到临时工作时，切换到 `草稿箱`。结果：你可以继续未命名草稿，不影响已保存表。

## 完成标志

- 常用表已命名保存，并可从列表稳定加载。
- 文件夹层级已按业务或项目划分完成。
- 草稿箱与已保存表切换后，当前工作区状态符合预期。

## 易错点

- 已加载但未修改的表，保存按钮可能不可用，这是为了避免无效覆盖。
- 直接删除表不可撤销，建议先确认是否已有替代版本。
- 误把草稿当已保存表时，刷新后可能找不到命名记录，关键节点请手动保存。
