# DDL 输出与分享

## 使用对象

适合已经完成表结构配置，准备对外评审、协作确认或交付 SQL 的使用者。

## 解决问题

你可以明确“复制什么”“分享后别人能做什么”，避免协作时发错内容或误以为分享页可直接编辑。

## 操作步骤

1. 在右侧输出区先看 `建表 DDL`。结果：你能确认 `CREATE TABLE` 是否符合预期结构。
2. 切换到 `授权 DCL` 再检查授权语句。结果：你能把建表与授权分开交付，减少执行遗漏。
3. 按需点击 `复制DDL` 或 `复制DCL`。结果：语句进入剪贴板，可直接粘贴到评审文档或执行系统。
4. 点击顶部 `分享链接`。结果：系统生成可访问的只读链接并自动复制，默认有有效期。
5. 接收方打开链接后如需继续编辑，点击页面提示中的 `保存为副本并开始编辑`。结果：系统返回首页并加载可编辑副本，不会改动原分享视图。
6. 协作过程中可使用顶部 `帮助文档`、`语言`、`主题` 入口。结果：成员可快速查阅说明、按语言进入对应文档并调整阅读环境。

## 完成标志

- 需要交付的 DDL 或 DCL 已正确复制并发送。
- 分享链接已验证可打开，接收方能看到完整只读内容。
- 需要继续修改时，已成功转成可编辑副本。

## 易错点

- 分享页默认是只读，不能直接作为在线编辑页使用。
- 只复制 DDL 不复制 DCL，可能导致建完表但权限未同步下发。
- 分享链接过期后会失效，建议在关键评审窗口重新生成一次。
