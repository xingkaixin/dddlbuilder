# 快速开始

## 使用对象

适合第一次使用筑表师，目标是尽快完成一张表的建表语句并复制使用。

## 解决问题

你不需要从零手写 SQL。通过页面配置，你可以在几分钟内得到可用的建表 DDL 和授权 DCL。

## 操作步骤

1. 在表配置区域选择数据库类型，并填写表名、表中文名。结果：系统明确目标数据库语法，并建立当前表对象。
2. 在“字段配置”里填写字段名、字段类型、是否为空、默认类型。结果：右侧“建表 DDL”开始实时生成可读 SQL。
3. 按需切换到“索引配置”“授权配置”“杂项设置”补充信息。结果：DDL 与 DCL 会随配置自动更新。
4. 在右侧输出区点击“复制DDL”或“复制DCL”。结果：语句进入剪贴板，可直接发给评审或执行。
5. 需要长期保留时，点击表名右侧保存按钮并命名。结果：该表进入“已保存表”，后续可随时加载。

## 完成标志

- 右侧“建表 DDL”出现完整 `CREATE TABLE` 语句。
- 点击复制后出现“已复制”反馈。
- 打开“查看已保存表”能看到刚保存的表。

## 易错点

- 数据库类型选错时，生成语句会与目标库不匹配，先改数据库类型再继续编辑。
- 只配置字段、未配置授权对象时，“授权 DCL”可能为空，这是正常表现。
- 没有保存就关闭页面，虽然草稿会自动保留，但建议关键节点手动保存一份命名表。
