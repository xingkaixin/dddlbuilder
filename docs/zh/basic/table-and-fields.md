# 表与字段配置

## 使用对象

适合已经进入编辑页面，准备把一张业务表从“空白”配置成“可生成 DDL”的使用者。

## 解决问题

你可以在一个界面里完成表级信息与字段级信息录入，快速形成可评审的表结构草案。

## 操作步骤

1. 在“表配置”中填写 `表名`、`表中文名`，并确认 `数据库类型`。结果：系统按目标数据库语法生成后续 SQL。
2. 在“字段配置”逐行录入 `字段名`、`字段中文名`、`字段类型`。结果：基础字段结构实时出现在右侧 DDL。
3. 按字段规则设置 `是否为空`、`默认类型`、`默认值`、`更新策略`。结果：字段约束和默认行为写入 SQL。
4. 使用工具栏 `添加行` 批量补充字段，必要时开启 `冻结` 保持关键列可见。结果：大表编辑效率更高，横向滚动不易看错列。
5. 需要复用字段时，通过 `应用模板` 选择已有模板，或把当前字段保存为模板。结果：同类表可以快速复用统一字段集。
6. 需要预估体量时，点击 `估算容量` 调整预计行数。结果：你可以得到单行大小和总量级估算，用于前期容量沟通。

## 完成标志

- 字段列表已覆盖本表核心字段，且每行字段信息完整。
- 右侧 DDL 已随字段变化实时更新，没有空白结构。
- 若使用模板，模板字段已成功落到当前表格中。

## 易错点

- 字段名重复或命中保留字时会有告警，建议先改名再继续配置。
- 只填写字段名不设置字段类型，会导致结构信息不完整。
- 大批量粘贴后，建议逐列抽查“默认类型”和“更新策略”，避免错位。
