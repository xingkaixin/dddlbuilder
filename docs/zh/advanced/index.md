# 高级技巧

## 使用对象

适合已经能完成常规建表，准备处理“导入存量 SQL、AI 协作、结构变更控制、分区分片策略”等复杂场景的使用者。

## 解决问题

高级技巧帮助你把“能生成 SQL”推进到“可稳定复用、可协作评审、可控制变更风险”。

## 前置条件

- 你已经完成基础指南中的常规建表流程。
- 你知道如何在页面中查看 DDL 与 DCL 输出。

## 建议阅读顺序

1. [导入与解析 SQL](/zh/advanced/import-and-parse)
2. [AI 辅助建表流程](/zh/advanced/ai-workflow)
3. [评审与解释 SQL](/zh/advanced/review-and-explain)
4. [分区与分片配置](/zh/advanced/partition-and-sharding)
5. [变更对比与回滚](/zh/advanced/diff-and-rollback)

## 与基础指南的分界

- 基础指南关注“如何完成一张表的常规配置和输出”。
- 高级技巧关注“如何在复杂场景下提高质量、控制风险、提升协作效率”。
